0-1　Bits, Bytes, Binary and HexadecimalLearning how computers count, by working it out by hand

Network and security tools keep showing you numbers like 5e:f1:1e:25:27:db, 192.168.128.3, “148 bytes” and port “65535”. Every one of them is the computer’s internal bits and bytes, rewritten in a form that is easier for people to read.

In this section you will learn binary, which writes numbers with only 0 and 1; the byte, a group of 8 bits; and hexadecimal, a short way to write bytes. You will then check the arithmetic in a terminal on Parrot. Finally, you will reread Parrot’s MAC address (MAC: Media Access Control) and IP address (IP: Internet Protocol) by asking “how many bytes is this?” and “what does each bit mean?”

§01

Bits — representing everything with 0 and 1

Key points of this section
  • All information inside a computer is a sequence of 0s and 1s. Each single digit is a bit.
  • Binary reads each digit as a power of 2. 8 bits (= 1 byte) hold 0–255.
  • Hexadecimal writes 4 bits as one character. 1 byte = 2 hex digits.
  • A MAC address is 6 bytes, an IPv4 (Internet Protocol version 4) address is 4 bytes, and a port number is 2 bytes.

Inside a computer, information is handled by telling apart just two states: current flowing or not flowing, voltage high or low. The two states are written as the digits 1 and 0.

A single “0 or 1” digit is called a bit (short for binary digit). One bit can only represent two values, 0 and 1, but as you line up more bits, the number of values you can represent grows quickly.

P1Computers distinguish only two states, 0 and 1Principle — memorize

What kind of rule: a design convention. It is not a law of nature; computers are simply built this way.

Origin: with only two states, a little noise in the voltage is unlikely to cause a misreading (it is robust against noise), so today’s computers work this way. The word “bit” spread through Claude Shannon’s 1948 paper “A Mathematical Theory of Communication” (the name itself was coined by his colleague John Tukey).

Each extra bit doubles the number of values. Doubling n times is called “2 to the power of n” and written 2ⁿ (the small raised number says how many times to multiply). For example, 2³ is 2×2×2 = 8.

Number of bitsCalculationValues

Principle used: P1

How to derive: adding one bit lets you append a 0 or a 1 to every existing pattern, so the number of values doubles. Start from 2 values for 1 bit and double n times to get 2ⁿ. Since counting starts at 0, the largest value is 2ⁿ−1.

If the principle were different: if each digit could take three states, n digits would give 3ⁿ values.

§02

Binary — reading by place value

The decimal system we use every day has ten digits, 0–9, and each step to the left is worth 10 times more. 305 means “3×100 + 0×10 + 5×1”. The size that a position stands for is called its place value.

Binary uses only two digits, 0 and 1, and each step to the left is worth 2 times more. A sequence of bits can be read directly as a binary number.

P2Positional notation: each place value is a power of the basePrinciple — memorize

What kind of rule: a mathematical definition. The place values are 10ⁿ in decimal, 2ⁿ in binary and 16ⁿ in hexadecimal (the base is the number of digits the system uses). In every base, the rightmost place is the 0th power, which is 1.

Origin: decimal positional notation with a zero was developed in ancient India and spread through the Arab world. Gottfried Leibniz studied binary systematically (1703).

The place values of an 8-digit binary number. The rightmost digit is the lowest place.

Decimal → binary: subtract place values from the largest down

To go the other way, work from the largest place value down: write 1 if you can subtract it from what is left, and 0 if you cannot.

D2Converting binary ⇄ decimalDerivation — derive it yourself

Principle used: P2

How to derive: binary → decimal: add each digit × its place value (a power of 2). Places holding 0 vanish, so you just add the place values of the 1s. Decimal → binary: from the largest place value down, write 1 whenever it can be subtracted from what is left.

With a different base: use 16 and the same steps convert hexadecimal (D4 in §04).

Conventions for writing binary

Binary 10 is read “one-zero”, not “ten”, and its value is 2. To tell binary apart from decimal, programs sometimes write a 0b prefix, as in 0b1010 (the same idea as the 0x for hexadecimal in §04). Numbers are also sometimes padded with 0s on the left to a fixed number of digits: 1010 and 00001010 are both 10.

Calculation drill (§02, 3 questions)

Q1Reproduce: D2Convert these binary numbers to decimal using place values.
(a) 0110　(b) 10000000　(c) 10101000　(d) 00000011

Work out your own answer first

Uses: P2 (place value)

Add only the place values where there is a 1.

(a) 0110 = 2² + 2¹ = 4 + 2 = 6

(b) 10000000 = 2⁷ = 128

(c) 10101000 = 2⁷ + 2⁵ + 2³ = 128 + 32 + 8 = 168

(d) 00000011 = 2¹ + 2⁰ = 2 + 1 = 3 (leading 0s do not change the value)

The 128, 168 and 3 in (b)–(d) are numbers in Parrot’s IPv4 address 192.168.128.3 (§06).

Q2Reproduce: D2Convert these decimal numbers to 8-digit binary (use the subtract-from-the-largest method).
(a) 10　(b) 64　(c) 200　(d) 255

Work out your own answer first

Uses: P2, D2

(a) 10 = 8 + 2 = 2³ + 2¹ → 00001010

(b) 64 = 2⁶ → 01000000

(c) 200: subtract 128, leaving 72; subtract 64, leaving 8; 32 and 16 cannot be subtracted; subtract 8, leaving 0 → 2⁷ + 2⁶ + 2³ → 11001000

(d) 255 = the sum of all place values → 11111111

Q3Reproduce: D1(a) How many values can 4 bits represent, and what is the largest of them in decimal? (b) What about 12 bits?

Work out your own answer first

Uses: P1, D1

(a) 2⁴ = 16 values. Counting from 0, the largest is 16−1 = 15 (1111).

(b) 2¹² = 4,096 values. The largest is 4,095.

For n bits: “2ⁿ values, the largest is 2ⁿ−1”. The 256 values with a maximum of 255 for 8 bits, and the 65,536 values with a maximum of 65,535 for 16 bits, follow the same pattern. The 16 values in (a) are exactly the digits of one hexadecimal place (0–f) in §04.

§03

Bytes — groups of 8 bits

A single bit carries too little information, so computers handle 8 bits as one unit. This unit is called a byte. Data sizes, file sizes and packet sizes are normally counted in bytes (in 1-4, for example, you will see a 148-byte packet).

P31 byte = 8 bitsPrinciple — memorize

What kind of rule: a convention (an agreement shared by almost every computer today).

Origin: the 8-bit byte spread after IBM’s System/360 adopted it in 1964. Before that, some machines used 6-bit units and the like, so network standards documents (RFC: Request for Comments) call 8 bits an “octet” to avoid any ambiguity.

8 bits can represent 2⁸ = 256 values, so one byte holds the numbers 0–255 (256 numbers counting from 0). The numbers in an IPv4 (Internet Protocol version 4) address only go up to 255 because each number is one byte (§06).

D3A byte holds 256 values, 0–255Derivation — derive it yourself

Uses: D1, P3

How to derive: 1 byte = 8 bits (P3), so D1 with n = 8 gives 2⁸ = 256 values. Counting from 0, the largest is 255.

If the principle were different: on a machine with 6-bit bytes, a byte would hold 0–63.

Units for bits and bytes

A lowercase b stands for bits and an uppercase B for bytes. Network speeds are usually given in bits and file sizes in bytes, so be careful not to mix them up.

Basis: P3

100 Mbps is 12.5 MB per second. Mixing them up throws estimates of time or capacity off by a factor of 8 (Q5).

Calculation drill (§03, 2 questions)

Q4Reproduce: D3(a) How many bits are 3 bytes? (b) How many bytes are 32 bits? (c) How many bits is a 148-byte packet (it appears in 1-4)?

Work out your own answer first

Uses: P3

1 byte = 8 bits, so bytes → bits is ×8 and bits → bytes is ÷8.

(a) 3×8 = 24 bits　(b) 32÷8 = 4 bytes (one IPv4 address)　(c) 148×8 = 1,184 bits

The 1,184 bits in (c) is the number tshark shows in 1-4 §05 as 148 bytes on wire (1184 bits).

Q5Apply: P3 → C1You send a 50 MB file over a 100 Mbps line. Ignoring headers and the like, what is the shortest time it can take? (Take 1 MB = 1,000,000 bytes.)

Work out your own answer first

Uses: P3 → C1

Convert everything to bits. 50 MB = 50×8 = 400 Mb (megabits).

400 Mb ÷ 100 Mbps = 4 seconds.

Confuse b (bits) with B (bytes) and the answer is off by a factor of 8 (you would get 0.5 or 32 seconds). In practice it takes a little longer, because of headers and acknowledgements.

§04

Hexadecimal — 4 bits in one character

Binary uses only 0 and 1, so numbers quickly get long: 8 digits for a single byte, 48 digits for a MAC address (6 bytes). To write bit patterns more compactly, we use hexadecimal.

Hexadecimal uses 16 different characters. The values 10–15 that come after 0–9 cannot be written with a single decimal digit, so the letters a–f are used.

Four binary digits (4 bits) have 16 values, 0000–1111, so they map to exactly one hexadecimal digit. Split one byte (8 bits) into two groups of 4 bits and it can be written as 2 hex digits.

D44 bits = 1 hex digit, 1 byte = 2 hex digitsDerivation — derive it yourself

Uses: D1, P2, P3

How to derive: by D1, 4 bits have 2⁴ = 16 values. One hex digit also has 16 values, 0–f, so they match exactly. One byte (P3) is two groups of 4 bits, so it takes 2 digits. Converting to decimal only means using powers of 16 as the place values in P2.

With a different base: octal uses groups of 3 bits (2³ = 8). It is used for file permissions (chmod 644) in 0-3.

Converting hexadecimal to decimal also uses place values. In hexadecimal, the rightmost place is 16⁰ = 1 and the next one to the left is 16¹ = 16.

Conventions for writing hexadecimal
  • To tell hexadecimal apart from decimal, a 0x prefix is sometimes added (0xff = 255). 0x itself is not part of the value; it only says “this is hexadecimal”.
  • Uppercase a–f (A–F) mean the same thing: 5E and 5e are the same.
  • Always write a byte as 2 digits: write 10 as 0a, not a (so that the digits in a MAC address and the like do not shift).

Q6Reproduce: D4Convert these hexadecimal numbers to decimal.
(a) 0x1f　(b) 0x80　(c) 0xa8　(d) 0x1f90 (4 digits)

Work out your own answer first

Uses: P2, D4

For two digits: “left digit × 16¹ + right digit × 16⁰”. a = 10, b = 11, c = 12, d = 13, e = 14, f = 15.

(a) 1×16 + 15 = 31　(b) 8×16 + 0 = 128　(c) 10×16 + 8 = 168

(d) With 4 digits, the place values from the left are 16³ = 4,096, 16² = 256, 16¹ = 16 and 16⁰ = 1.
1×4,096 + 15×256 + 9×16 + 0×1 = 4,096 + 3,840 + 144 + 0 = 8,080

The 8080 in (d) is the port number used for the web server in 1-2 (Figure 14 in §06).

Q7Reproduce: D4Convert these decimal numbers to 2-digit hexadecimal.
(a) 15　(b) 16　(c) 100　(d) 172

Work out your own answer first

Uses: P2, D4

Divide by 16: the quotient is the left digit and the remainder is the right digit.

(a) 15 = 0×16 + 15 → 0f　(b) 16 = 1×16 + 0 → 10

(c) 100 = 6×16 + 4 → 64　(d) 172 = 10×16 + 12 → ac

Hexadecimal 10 in (b) is 16, not “ten”, and hexadecimal 64 in (c) is 100. The same characters have different values depending on the base, which is why 0x is added to tell them apart.

Q8Reproduce: D4Convert these binary numbers to hexadecimal (split them into groups of 4 bits).
(a) 1010 1100　(b) 0001 0010　(c) 1111 0000

Work out your own answer first

Uses: D4

(a) 1010 = 10 = a, 1100 = 12 = c → ac (the same number as 172 in Q7 (d))

(b) 0001 = 1, 0010 = 2 → 12

(c) 1111 = 15 = f, 0000 = 0 → f0

The 12 in (b) is the first byte of Kali’s MAC address on the internal network, 12:ae:d8:64:04:33 (Q9).

§06

Reading real addresses in bytes (Parrot)

MAC addresses, IPv4 addresses and port numbers come up again and again in Chapter 1, so let’s read them in terms of bytes and bits first. Keep using the terminal from Step 2; run clear before you start.

P4Address sizes are fixed by standards: MAC 48 bits, IPv4 32 bits, port numbers 16 bitsPrinciple — memorize

What kind of rule: a standard. Changing it takes a new standard. When IPv4’s 32 bits ran short, a separate 128-bit standard, IPv6, was created (it is not an extension of IPv4 and cannot talk to IPv4 directly, which is why both are still used side by side).

Origin: MAC addresses come from the IEEE (Institute of Electrical and Electronics Engineers) 802 standards, which also define the meaning of bit 0 and bit 1 of the first byte. IPv4 is RFC 791 (1981). Port numbers come from RFC 768 for UDP (1980) and RFC 793 for TCP (1981; now RFC 9293).

C2MAC addresses can be generated and changed in software, so they cannot verify identityConclusion — explain it

Basis: D4, P4 (bit 1 of the first byte)

On a real NIC, the first 3 bytes of the MAC address are the OUI (Organizationally Unique Identifier: a number assigned to each manufacturer), the last 3 bytes are a serial number within that manufacturer, and bit 1 is 0. Virtual machine NICs, and smartphone “private address” features (which change the MAC address for each Wi-Fi network to make tracking harder), have the software generate the number, so bit 1 is 1. Because a MAC address can be changed in software, a MAC address alone cannot verify which device you are talking to. This weakness comes into play in Chapter 8 (ARP spoofing).

Because the size of each container is fixed by the standard. Numbers above 255, as in 192.168.300.1, and port numbers above 65535 do not exist. If you see one, it is either a misconfiguration or a deliberately malformed value.

Applied problems (§06, 4 questions)

Q9Apply: P4 → D4 → C2Kali’s MAC address on the internal network is 12:ae:d8:64:04:33 (it appears in 1-4 §04).
(a) Write the first byte, 12, as 8 binary digits, and say what bit 0 and bit 1 each mean.
(b) ARP (Address Resolution Protocol) “who has …?” queries are sent to the destination MAC address ff:ff:ff:ff:ff:ff (this appears in 1-1 §04). What is bit 0 of its first byte, and what does that mean?

Work out your own answer first

Uses: P4 (the meaning of bit 0 and bit 1), D4

(a) 0x12 = 1×16 + 2 = 18 = 16 + 2 = 2⁴ + 2¹ → 00010010.
Bit 0 (rightmost) = 0: a single device (unicast). Bit 1 (second from the right) = 1: a locally assigned address. As with Parrot, the number was generated by the virtualization software.

(b) ff = 11111111, so bit 0 is 1 = a group address. ff:ff:ff:ff:ff:ff (all 48 bits set to 1) is a special group address meaning “everyone on the same network” (the broadcast address). That is why an ARP “who has …?” query reaches everyone.

Q10Apply: D5The exit for Parrot’s NAT side (the internet side) is the Mac at 192.168.64.1 (it appears in 1-3). Write this address as 8 hex digits, and say how many bytes it is.

Work out your own answer first

Uses: D3, D4

Turn each of the four numbers into 2 hex digits.

192 = 12×16 + 0 → c0, 168 = 10×16 + 8 → a8, 64 = 4×16 + 0 → 40, 1 → 01

Answer: c0a84001 (8 hex digits = 4 bytes).

The leading c0a8 (192.168) is the same as in 192.168.128.3 in §06. Only the third number differs (64 versus 128), and in hexadecimal that shows up as 40 versus 80.

Q11Apply: P4 → D1 → C4, C5(a) Explain, in terms of the number of bits, why port number 70000 cannot be used. (b) What is the smallest number of bits needed to represent 70000?

Work out your own answer first

Uses: P4, D1

(a) A port number is a container of 2 bytes = 16 bits, which holds values only up to 65,535 (2¹⁶−1). 70,000 is larger, so it does not fit in the container and cannot be used.

(b) 2¹⁶ = 65,536 is not enough, but 2¹⁷ = 131,072 is, so 17 bits.

What happens when you try to put a number or data that does not fit into a fixed-size container is a very important topic in security. Chapter 12 deals with the same problem for containers in memory, under the name buffer overflow.

Q12Apply: P4 → D5 (a standard you have not seen yet)An IPv6 address is 128 bits. (a) How many bytes is it? (b) How many hex digits? (c) How many IPv6 addresses are there in total, as a power of 2? How many times as many as IPv4, as a power of 2?

Work out your own answer first

Uses: P3, P4, D1, D4

This section does not cover IPv6, but if you understand the principles and derivations, you can still solve it.

(a) 1 byte = 8 bits (P3), so 128÷8 = 16 bytes.

(b) 1 byte = 2 hex digits (D4), so 16×2 = 32 digits (thinking of 4 bits = 1 digit gives 128÷4 = 32 as well).

(c) By D1, 2¹²⁸ addresses. IPv4 has 2³², so 2¹²⁸÷2³² = 2⁹⁶ times as many (dividing powers of the same number subtracts the exponents: 128−32 = 96).

Real IPv6 addresses are written as 32 hex digits split into groups of 4 by : (for example, 2001:0db8:0000:0000:0000:0000:0000:0001; the range starting with 2001:db8:: is reserved for documentation). The addresses starting with fe80:: that appear in 1-3 are also IPv6 addresses.

§07

Where bytes and hex show up

Bytes and hexadecimal come up again and again later in the course. In every case, if you can read “how many bytes” and “how many hex digits”, you can make sense of what is displayed.

  • Packet size and contents: in 1-4 you will check that a 148-byte packet breaks down into Ethernet 14 + IP 20 + TCP 32 + HTTP 82 bytes. In 0-2, you will learn how to display the contents of files and packets as 2-digit hex numbers in a row (a hex dump).
  • Hash values: a value that acts as a file’s “fingerprint”. SHA-256 is 256 bits = 32 bytes, shown as 64 hex digits. In the malware analysis in Chapter 14, you will use it to check whether a file is known malware.
  • Memory addresses: where a program is in memory is shown in hexadecimal, such as 0x7ffd… (0-4, Chapter 12).
  • Size limits: the sense that “a byte holds only up to 255” and “what happens if you write data larger than a fixed-size container” is the foundation of buffer overflows in Chapter 12.
C5Numbers or data that do not fit a fixed size can become security weaknessesConclusion — explain it

Basis: D3, D5

Writing into a container without checking its size damages the area next to it. A buffer overflow (Chapter 12) is this problem happening in memory (Q11).

§08

Summary and checklist

The path through this article (review)

The blue, green and orange frames from the text are gathered into a single diagram. If you remember just the principles on the left, you can rebuild the derivations in the middle on your own and explain the conclusions on the right.

  • Information inside a computer is a sequence of 0s and 1s. Each digit is a bit, and n bits can represent 2ⁿ values.
  • Binary reads each digit as a power of 2 (…, 2³ = 8, 2² = 4, 2¹ = 2, 2⁰ = 1); adding the place values of the 1s gives the decimal value.
  • 8 bits = 1 byte, which has 256 values, 0–255. In units, b is bits and B is bytes.
  • Hexadecimal uses 16 characters, 0–9 and a–f. 4 bits = 1 digit, so 1 byte = 2 hex digits. 0x marks a hexadecimal number.
  • A MAC address is 6 bytes, an IPv4 address 4 bytes and a port number 2 bytes. If bit 1 of the first byte of a MAC address is 1, it is a locally assigned number generated by software.
  • In the terminal, you can check conversions with echo $((base#number)), printf '%02x' and python3 -c "print(format(number, '08b'))".
