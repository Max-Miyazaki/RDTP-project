3-2　南ヨーロッパ東経0度から東へ、17か国を置く

3-1 の西ヨーロッパに続いて、南ヨーロッパの17か国を置きます。東経0度から東回りに、アンドラで始まり、ギリシャを通って、最後はイベリア半島のポルトガル・ジブラルタル・スペインで終わります。東経0度より西にある3つが最後に来るのは、2-1 で決めた「輪の切れ目は東経0度に1つだけ」という規則のとおりです（§03）。

この回で覚えるのは形・位置・隣り合い・首都と、国境の3つの欄です。3-1 と同じく、国ごとの川や道路、区分や都市は17か国それぞれの国のページが持っています（§08）。

01

この回の到達目標

  1. 白紙の升目に17か国を描き、東経0度から東回りの順を言える北緯30〜60度の段の、西経30度〜東経30度の2つのマスに、アンドラからスペインまで。最後のスペインが、輪の上では最初のアンドラと隣り合うことも言えること（§03・§04、演習1〜3）。
  2. 17か国の首都を言え、国境の3つの欄で3つの場所を説明できるコソボ（承認：数える人で数が違う）、ジブラルタル（主張：スペインが主張している）、サンマリノとバチカン（イタリアに囲まれている）（§05・§07、演習4）。
  3. この地域が3本の横断する軸の上で、西ヨーロッパとどう違うかを数で言えるプレートの境界の線がイタリアとギリシャの国の中を通る。地震は国境の100km以内に220件（西ヨーロッパは6件）。ケッペンでは帯の予想と90.8%が食い違うが、外れ値の場所は1つもかからない。エーゲ海は漂流ブイの観測が無い（§06、演習5・6）。
前提の確認

3-1 の白紙の9か国（演習1で17点以上）と、東回りと西回りが止まらずに言えることを確かめてから入ってください。この回の17か国は、西ヨーロッパの南と東に接しています。フランスはスペイン・イタリア・アンドラと、スイスはイタリアと、オーストリアはイタリア・スロベニアと接しています（3-1 §04「域外で接する国」）。

02

この回の見方

3-1 と同じ型、節が1つ増える

記事は位置を置き、国の詳細は国のページが持ちます（記事＝訓練、国のページ＝参照）。§06「横断する軸——3本」までは 3-1 と同じ型です。この回はそのあとに§07 国境を足しました。3-1 の地域には係争地がありませんでしたが、南ヨーロッパにはコソボとジブラルタルがあるためです（付録A）。

地域のカードは、横に送って見る

§04・§05 のカードは、国のページと同じ1度44pxで描いています。17か国は東西に約36度（島を含めると約38度）あるので、カードの幅は1,234pxになり、本文の列に収まりません。縮めずに、横に送って見てください。全体を一度に見たいときは、カードの右上の「拡大 ⤢」で画面いっぱいに広げられます。広げた画面では縮尺が変わるので、左下に「覚えるための縮尺 1度44px の何倍か」が出ます。

違う縮尺の図には「この図だけ○倍」と書きます。この回では §04 の拡大図（アンドラ20倍・サンマリノ50倍・マルタ20倍）と、小さい国の国のページ（§08）がそうです。

カードは層で見る

層1が形、§04 の層2が拡大図、§05 の層3が首都です。まず層1だけで形と位置を言い、そのあとで層を足してください。層は1つずつ重ねて使います。

国境の描き方

国境は 2-1 §08 のとおり、実効支配（実際に治めている政府の範囲）で描いています。この地域には、2-1 §08 で扱ったコソボ（別の区域として描かれ、実効支配と合っている）と、ジブラルタルがあります。主張と承認は §07 で別の欄に書きます。元データは Natural Earth v5.1.2（1:1000万）です。

03

17か国は、2-1 の升目の北緯30〜60度の段にあり、西経30度〜東経0度と東経0〜30度の2つのマスにまたがります。東経0度はスペインを通ります（2-1 §05 で北から南へ、イギリス → フランス → スペインとたどった線です）。

東西は約36度、南北は約11度。3-1 の西ヨーロッパ（東西約22度・南北約13度）より東西に長く、地中海の北の岸に沿って並びます。17か国の本土の中心は北緯42.2度・東経6.6度です（2-1 付録Aの表では丸めて「北42° 東7°」）。

輪の切れ目——イベリアが最後に来る

東経0度で切って東回りに並べるので、東経0度より西にあるポルトガル・ジブラルタル・スペインは最後に来ます。輪の上では、最後のスペインは最初のアンドラと隣り合っています（アンドラはスペインとフランスのあいだ）。2-1 の付録Aで、地域の輪の切れ目を東経0度に1つだけ置き、西アフリカが最後に来ると書いたのと同じ規則です。規則を曲げずに当てはめた結果です。

大西洋の島は、この回の地図の外

スペインのカナリア諸島（北緯28.3度・西経15.7度）、ポルトガルのアゾレス諸島（北緯38.4度・西経27.3度）とマデイラ諸島（北緯32.8度・西経17.0度）は、この回のカードの範囲の外にあります。国のページでは、日本の南西諸島と同じく別の図にしています（§08）。

日本と同じ緯度に並べる

日本と同じ北緯30〜60度の段です。西ヨーロッパは日本より北でしたが、南ヨーロッパは日本とほぼ重なります。ローマ（北緯41.9度）は函館（北緯41.8度）、アテネ（北緯38.0度）は仙台（北緯38.3度）、マルタのバレッタ（北緯35.9度）は東京（北緯35.7度）とほぼ同じ緯度です（Natural Earth の人口地点）。

隣り合いから読める構造
  • 要はセルビアとモンテネグロ——域内でそれぞれ5か国と接する。セルビアは域外の3か国を足すと8か国で、この地域でいちばん多い

06

横断する軸——3本

3-1 と同じく、2章で立てた3本の軸——2-1 の \(\cos\varphi\)、2-2 のプレートの境界、2-3 の気候の帯と海流——の上に、この地域を置きます。書くのはどこにあるかだけで、なぜそうなるかは「地球と人類」第I部 第1章（準備中）が受け持ちます。西ヨーロッパと違うところが、この節の中心です。

① \(\cos\varphi\)——展開図で何倍に見えるか

17か国の本土は北緯35.8〜47.1度にあり、2-1 の展開図では東西に1.23〜1.47倍に伸びて見えます。西ヨーロッパ（北緯42.3〜54.9度で1.35〜1.74倍）より倍率が小さく、幅も狭い——南にあるぶん、展開図の歪みが少ない地域です。

§04 のカードは標準緯線を北緯42度に置いたので、東西の縮みと伸びは \(\cos 42^\circ/\cos\varphi\) で、南の端（北緯35.8度）で約0.92倍、北の端（北緯47.1度）で約1.09倍です。展開図の1.23〜1.47倍に比べると、ずれは4分の1ほどに減っています。

② プレートの境界——境界の線が国の中を通る

2-2 §04 のカードで、境界の線と造山帯（斜線）を重ねて見てください。3-1 では、境界の線は9か国のどこも通らず、いちばん近いところでも約300km でした。南ヨーロッパでは、境界の線がイタリアとギリシャの国の中を通ります。

  • イタリア——アフリカとユーラシアの境界の線が、シチリア島の北の小さな島々（エオリエ諸島）と、シチリア島とイタリア半島のあいだ（メッシーナ海峡）で国の中を通る
  • ギリシャ——エーゲ海プレートとユーラシアの境界の線が、ギリシャの中部（コリントス湾のあたり）を東西に約160km 通る。南西の沖（イオニア海の島から約26km、クレタ島から約28km）には、エーゲ海プレートとアフリカの「近づく」境界がある

帯の予想がいちばん外れる地域——ただし「外れ値」とは重ならない

12か国の陸のうち90.8%で、実際のケッペンの分類が帯の予想と食い違います（3-1 の西ヨーロッパは81.3%、世界の陸全体は33.7%）。食い違いの88.2%は「中緯度の帯は B（乾燥）と予想するが、実際は C」です。中緯度の帯の陸でいちばん多いのは乾燥した B（2-3 §08）ですが、この地域はほとんどが C です。

3-1 では、「その緯度にしては暖かすぎる場所（外れ値）」と「食い違う場所」が重なっていました。南ヨーロッパには、2-3 の外れ値の場所（降水量13か所・気温11か所）が1つもかかりません。だから 3-1 の「重なる」は、ここでは成り立ちません。食い違いは多いが、その緯度として異常な量ではない——西ヨーロッパとは別の形の「外れ方」です。なぜそうなるかは、地球と人類 第I部 第1章（準備中）で扱います。

ジブラルタルの主張

  • スペイン外務省：ジブラルタルはユトレヒト条約でイギリスに割譲された。ただし割譲されたのは町と要塞で、地峡（いまの空港のあたり）は割譲されておらず、スペインの主権の下にあると主張している。フェンスを国境とは認めていない

  • 東経0度をスペインの西の端に引く——東経0度はスペインの東寄り（バレンシアの近く）を通り、スペインの大部分は東経0度より西にある
  • ボスニア・ヘルツェゴビナを海から離す——南のネウムのあたりで、短くアドリア海に面している。そのためクロアチアの南の端が切れる
  • コソボと北マケドニアの上下を逆にする——コソボが北、北マケドニアが南（その南がギリシャ）
演習2西回りと、輪の切れ目

(1) 17か国を、西回り（スペインからアンドラへ）に言ってください。(2) 東経0度から東回りに並べると、ポルトガル・ジブラルタル・スペインが最後に来るのはなぜですか。輪の上で、最後のスペインは何番目の国と隣り合っていますか。

解答

(1) スペイン → ジブラルタル → ポルトガル → ギリシャ → 北マケドニア → コソボ → セルビア → アルバニア → モンテネグロ → ボスニア・ヘルツェゴビナ → クロアチア → スロベニア → マルタ → バチカン → サンマリノ → イタリア → アンドラ

(2) 3つとも中心が東経0度より西（西経8.0度・5.4度・3.6度）にあり、東経0度で切って東回りに数えると、いちばん遠い側になるから（2-1 付録Aの輪の切れ目と同じ規則）。スペインは、1番目のアンドラと接している

演習3隣り合う国と、囲まれた国

(1) 域内でいちばん多くの国と接する国を2つ言ってください。(2) 1か国とだけ接する国を4つ言ってください。陸の隣国が無い国はどこですか。(3) 海に面していない国をすべて言ってください。この中に二重内陸国はありますか。(4) 周りをすべて1つの国に囲まれた国は、この地域に2つあります。世界でほかにどこがありますか。

解答

(1) セルビアとモンテネグロ（域内でそれぞれ5か国）。セルビアは域外の3か国を足すと8か国

(2) サンマリノ・バチカン（イタリアとだけ）、ポルトガル・ジブラルタル（スペインとだけ）。陸の隣国が無いのはマルタ

(3) 6か国：北マケドニア・コソボ・セルビア・アンドラ・サンマリノ・バチカン。二重内陸国は無い（どの国も、海に面した国と少なくとも1つ接している。サンマリノとバチカンの隣のイタリアも海に面している）

(4) レソト（南アフリカ共和国に囲まれる）。Natural Earth の国の形で数えると、この3つ（サンマリノ・バチカン・レソト）だけ

演習4首都と国境の欄

(1) 17か国の首都を東回りの順に言ってください（ジブラルタルは飛ばす）。(2) コソボについて、実効支配・主張・承認の3つの欄を言ってください。承認の数が1つに決まらないのはなぜですか。(3) ジブラルタルについて、スペインの主張の中で「地峡」はどういう位置づけですか。(4) サンマリノとバチカンを国境の欄に入れたのはなぜですか。

解答

(1) アンドラ・ラ・ベリャ → ローマ → サンマリノ → バチカン → バレッタ → リュブリャナ → ザグレブ → サラエヴォ → ポドゴリツァ → ティラナ → ベオグラード → プリシュティナ → スコピエ → アテネ → リスボン →（ジブラルタル）→ マドリード

(2) 実効支配：コソボの政府。主張：セルビアが自国の一部と主張。承認：数える人で数が違う——コソボ外務省の一覧は121（2026年5月の更新）、セルビア外務省は「29か国が撤回・停止した」（2025年11月）としていて、同じ時点の数が一致しない

(3) スペイン外務省は、ユトレヒト条約で割譲されたのは町と要塞で、地峡（空港のあたり）は割譲されておらずスペインの主権の下にある、と主張している

(4) 周りをすべてイタリアに囲まれていて、国境が1つの国とだけある、という世界でも珍しい形だから（争いは無い）

演習5cos φ——西ヨーロッパと比べる

(1) 17か国の本土は北緯何度から何度までにありますか。2-1 の展開図では東西に何倍から何倍に伸びて見えますか。西ヨーロッパと比べて、どう違いますか。(2) 17か国の面積は、2-1 の展開図で約何倍に見えますか。西ヨーロッパでは何倍でしたか。(3) ローマ・アテネ・バレッタと、ほぼ同じ緯度の日本の都市を言ってください。

解答

(1) 北緯35.8〜47.1度で、1.23〜1.47倍。西ヨーロッパ（1.35〜1.74倍）より倍率が小さく、幅も狭い

(2) 約1.34倍。西ヨーロッパは約1.51倍

(3) ローマは函館、アテネは仙台、バレッタは東京

演習63本の軸——西ヨーロッパとの違い

西ヨーロッパ（3-1）と比べて、南ヨーロッパの3本の軸の違いを6つ言ってください。

解答
  • cos φ：1.23〜1.47倍（西ヨーロッパは1.35〜1.74倍）。倍率が小さく、幅も狭い
  • 境界の線：イタリアとギリシャの国の中を通る（西ヨーロッパは9か国のどこも通らず、最も近くて約300km）
