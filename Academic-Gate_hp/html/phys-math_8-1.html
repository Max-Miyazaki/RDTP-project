物理数学 I ／ 8章 ベクトル解析 ／ SECTION 8-1

8-1　ベクトルと場各点に数を、各点に矢印を

7章では、密度のように各点に1つの数を持つ量を、面積や体積の上で足し上げました。この章では、各点に矢印を持つ量を扱います。

空間の各点に何かの量が割り当てられているものを場といいます。電磁気学は電場と磁場の理論であり、場の量子論では電子や光子そのものが場として記述されます。現代物理は、場の言葉で書かれているのです。

この記事では、場を扱うための土台として、3次元のベクトル・内積・外積を整え、場の種類を「座標軸を回したときに、値がどう変わるか」で区別します。最後に、矢印を持つ場を道に沿って足し上げる線積分を作ります。

読み方：解答は必ず閉じたまま、紙で挑戦してください。

§01

ベクトルを3次元で扱う

高校で学んだベクトルを、3次元の空間で使える形に整えます。ベクトルは、向きと大きさを持つ矢印です。この教材では \(\vec a\) のように矢印を付けて書きます。

ベクトルの書き方

高校では \(\vec a\) のように文字の上に矢印を付けて書きました。一方、物理の教科書や論文では、太字 \(\boldsymbol a\) で書くのが一般的です。電場なら \(\boldsymbol E\)、磁場なら \(\boldsymbol B\) と書かれます。

どちらも同じものを表します。この教材では、紙に手で書くときと同じ形になるよう、矢印 \(\vec a\) を使います（太字は手書きで区別しにくいので、手書きでは矢印を使う人が多いです）。物理の本を読むときは、太字の文字はベクトルと読み替えてください。

成分

座標軸を決めると、矢印は「\(x\) 方向にどれだけ、\(y\) 方向にどれだけ、\(z\) 方向にどれだけ進むか」の3つの数で表せます。これを成分といいます。

\[ \vec a=(a_x,a_y,a_z) \]

足し算や定数倍は、成分ごとに行います。

矢印の長さ（大きさ）は、三平方の定理を2回使うと求まります。床に落とした影の長さの2乗が \(a_x^2+a_y^2\)、そこに高さ \(a_z\) を加えて

\[ |\vec a|=\sqrt{a_x^2+a_y^2+a_z^2} \]

長さが 1 で、各座標軸の向きを向いたベクトルを \(\vec e_x,\ \vec e_y,\ \vec e_z\) と書き、基本ベクトルと呼びます。成分は「基本ベクトルを何倍して足すか」とも読めます。

\[ \vec a=a_x\vec e_x+a_y\vec e_y+a_z\vec e_z \]

内積 — 成分を取り出す操作

なぜ内積が必要か

台車にひもを付けて、斜め上に引っぱる場面を考えます。台車は床の上を前にしか進めません。このとき台車を進めるのに役立つのは、引く力のうち前向きの成分だけです。上向きの成分は、台車を持ち上げようとするだけで、前進には効きません。

物理では、このように「ある量の、特定の向きに効く部分だけを取り出したい」場面が何度も出てきます。

  • 力で物体を動かしたとき、力のうち動いた向きの成分だけが仕事になる
  • 斜面に置いた物体では、重力のうち斜面に沿った成分だけが物体を滑らせる
  • 流れが面を通り抜ける量は、流れのうち面に垂直な成分で決まる（8-3 で扱います）

この「特定の向きの成分を取り出す」を、どの向きに対しても同じ手順で計算できるようにしたものが内積です。仕事や力の分解の物理的な意味は、古典力学のセクションで扱います。

2つのベクトル \(\vec a\) と \(\vec b\) のなす角を \(\theta\) とします。

内積 \[ \vec a\cdot\vec b=|\vec a|\,|\vec b|\cos\theta \]

「\(\vec a\) の長さ」×「\(\vec b\) の \(\vec a\) 方向の成分」です。結果は矢印ではなく、ただの数です。

成分で計算する式も作っておきます。基本ベクトルどうしは、同じものなら長さ 1 で角 0 なので内積 1、違うものなら直交しているので内積 0 です。

\[ \vec e_x\cdot\vec e_x=1,\qquad \vec e_x\cdot\vec e_y=0 \]

\(\vec a\) と \(\vec b\) を基本ベクトルで書いて展開すると、同じ基本ベクトルどうしの項だけが残ります。

内積の成分表示 \[ \vec a\cdot\vec b=a_xb_x+a_yb_y+a_zb_z \]
内積は、ものさしを当てる操作

\(\vec a\) を長さ 1 のベクトル \(\vec e\) にすると、\(\vec e\cdot\vec b\) は\(\vec b\) の \(\vec e\) 方向の成分そのものになります。たとえば \(\vec e_x\cdot\vec b=b_x\) です。

内積は「好きな向きにものさしを当てて、その向きの成分を読む」操作です。§03 では軸を回したときの成分を、§04 では道に沿った成分を、この操作で取り出します。

まず自力で

\(\vec a=(1,1,0)\)、\(\vec b=(1,0,1)\) のなす角 \(\theta\) を求めてください。

HINT 1

内積を2通りに書きます。成分表示で値を出し、\(|\vec a|\,|\vec b|\cos\theta\) と等しいとおきます。

1成分で内積を計算する
なぜ：成分表示なら、角度を知らなくても値が出ます。
\[ \begin{aligned}\vec a\cdot\vec b&=1\cdot1+1\cdot0+0\cdot1\\&=1\end{aligned} \]
2長さを求める
なぜ：定義 \(|\vec a|\,|\vec b|\cos\theta\) の側に必要です。

\(|\vec a|=\sqrt2\)、\(|\vec b|=\sqrt2\) です。

3等しいとおく
なぜ：同じ内積の2つの表し方です。
\[ \sqrt2\cdot\sqrt2\cos\theta=1 \]

\(\cos\theta=\dfrac12\) なので、\(\theta=60^\circ\) です。

3次元の2本の矢印の角度は、図を描いて測るのが難しい量です。成分表示と幾何的な定義を等しいとおくと、計算だけで求まります。内積の2つの顔を行き来するのが、使いこなしのこつです。

計算ドリル（§01・全1問）

問1\(\vec F=(3,4,0)\) の、向き \(\vec u=(1,1,0)\) 方向の成分を求めよ。

自分の答えを出してから
HINT 1

ものさしは長さ 1 でなければなりません。まず \(\vec u\) を自分の長さで割って、長さ 1 にします。

\(|\vec u|=\sqrt2\) なので、長さ 1 の向きは

\[ \vec e=\frac{1}{\sqrt2}(1,1,0) \]

成分は内積で取り出します。

\[ \begin{aligned}\vec e\cdot\vec F&=\frac{3+4}{\sqrt2}\\&=\frac{7}{\sqrt2}\end{aligned} \]

よくある間違いは、長さ 1 にしないまま \(\vec u\cdot\vec F=7\) を答えにすることです。それは「成分 × \(\vec u\) の長さ」になっています。成分を取り出すものさしは、長さ 1。§04 の線積分でも、同じ注意が形を変えて出てきます。

この記事の到達目標
  • 内積を、成分を取り出す操作として説明し、成分で計算できる
  • 外積を成分で計算し、長さと向きの意味を説明できる
  • スカラー場とベクトル場を、座標軸を回したときの変わり方で区別できる
  • 線積分を、道を媒介変数で表して計算できる
  • 線積分が道によらないのはどんなときか、6-2 の完全微分と結びつけて説明できる
前提として使うもの
  • 高校数学：ベクトルの成分、内積
  • 7-2：平行四辺形の面積 \(|a_1b_2-a_2b_1|\)
  • 6-1・6-2：多変数関数、全微分、完全微分の条件
§02

外積 — 面積と、面の向き

なぜ外積が必要か

スパナでボルトを回す場面を考えます。同じ力で押しても、柄の端を持つほど、また柄に垂直に押すほどよく回ります。柄に沿ってまっすぐ押したのでは、まったく回りません。

つまり回す効果は「柄の長さ」×「力のうち柄に垂直な成分」で決まります。これは、柄のベクトルと力のベクトルが張る平行四辺形の面積そのものです。さらに、ボルトは回した結果、柄にも力にも垂直な向き（ボルトの軸の向き）に進みます。

物理では、このように「2つの向きから、両方に垂直な向きが生まれる」場面がよく出てきます。

  • 物を回す効果（力のモーメント）や、回転の勢い（角運動量）は、回転軸の向きを持つ
  • 磁場の中を動く電荷が受ける力は、動く向きにも磁場の向きにも垂直になる
  • 面の大きさと向きをまとめて表したいとき（8-3・8-4 で扱います）

「面積」と「両方に垂直な向き」を1本の矢印にまとめる操作が外積です。上の物理量の意味は、古典力学と電磁気学のセクションで扱います。

7-2 で、平面の2つのベクトル \((a_1,a_2)\)、\((b_1,b_2)\) が張る平行四辺形の面積が \(|a_1b_2-a_2b_1|\) であることを使いました。

3次元では、平行四辺形は空間の中でいろいろな向きを向けます。面積だけでなく、どちらを向いた面かも情報として必要です。

面の向きは、面に垂直な向きで指定できます。そこで、面に垂直で、長さが面積に等しい矢印を1本作れば、面積と向きを同時に表せます。

成分をどう決めるか

まず、\(\vec a\) と \(\vec b\) が \(xy\) 平面にある場合（\(a_z=b_z=0\)）を考えます。平行四辺形は床に寝ているので、垂直な向きは \(z\) 軸の向きです。長さは 7-2 の式から \(|a_xb_y-a_yb_x|\) です。したがって

\[ \vec a\times\vec b=(0,\ 0,\ a_xb_y-a_yb_x) \]

とすればよいはずです。

一般の向きの平行四辺形では、3つの座標平面に落とした影を考えます。\(xy\) 平面への影の面積が \(z\) 成分、\(yz\) 平面への影が \(x\) 成分、\(zx\) 平面への影が \(y\) 成分です。影の面積はどれも 7-2 と同じたすき掛けで求まるので、次の定義になります。

外積 \[ \begin{aligned}(\vec a\times\vec b)_x&=a_yb_z-a_zb_y\\(\vec a\times\vec b)_y&=a_zb_x-a_xb_z\\(\vec a\times\vec b)_z&=a_xb_y-a_yb_x\end{aligned} \]

覚え方：\(z\) 成分は 7-2 と同じ \(a_xb_y-a_yb_x\)。残りは、文字を \(x\to y\to z\to x\) と1つずつずらすと得られます。

外積の性質
  • 長さは平行四辺形の面積：\(|\vec a\times\vec b|=|\vec a|\,|\vec b|\sin\theta\)
  • 向きは \(\vec a\) と \(\vec b\) の両方に垂直で、\(\vec a\) から \(\vec b\) へ回す右ねじの進む向き
  • 順序を入れ替えると向きが逆になる：\(\vec b\times\vec a={-}\vec a\times\vec b\)
  • 平行なベクトルどうしの外積は \(\vec 0\)（平行四辺形がつぶれて面積 0）

内積の結果はただの数でしたが、外積の結果は矢印です。

まず自力で

\(\vec a=(1,2,0)\)、\(\vec b=(0,1,3)\) について、\(\vec a\times\vec b\) を計算してください。さらに、それが \(\vec a\) とも \(\vec b\) とも垂直であることを、内積で確かめてください。

HINT 1

成分の式に代入するだけです。垂直の確認は、内積が 0 になることを見ます。

1成分を1つずつ計算する
なぜ：外積の定義にそのまま入れます。
\[ \begin{aligned}x&:\ 2\cdot3-0\cdot1=6\\y&:\ 0\cdot0-1\cdot3={-}3\\z&:\ 1\cdot1-2\cdot0=1\end{aligned} \]

したがって \(\vec a\times\vec b=(6,{-}3,1)\) です。

2\(\vec a\) との内積
なぜ：内積が 0 なら、\(\cos\theta=0\) で直交しています。
\[ 1\cdot6+2\cdot({-}3)+0\cdot1=0 \]
3\(\vec b\) との内積
なぜ：同じく直交の確認です。
\[ 0\cdot6+1\cdot({-}3)+3\cdot1=0 \]

どちらも 0 で、垂直が確かめられました。外積の成分の式は、影の面積から作ったのに、ちゃんと両方に垂直な矢印になっているのです。計算ミスの検算にも、この内積 0 のチェックが使えます。

計算ドリル（§02・全1問）

問1基本ベクトルの外積 \(\vec e_x\times\vec e_y\)、\(\vec e_y\times\vec e_z\)、\(\vec e_z\times\vec e_x\) を成分で計算し、それぞれどの基本ベクトルになるか答えよ。

自分の答えを出してから

\(\vec e_x=(1,0,0)\)、\(\vec e_y=(0,1,0)\) を定義に入れると、\(z\) 成分だけが \(1\cdot1-0\cdot0=1\) で残ります。

\[ \vec e_x\times\vec e_y=\vec e_z \]

同じように計算すると

\[ \vec e_y\times\vec e_z=\vec e_x \] \[ \vec e_z\times\vec e_x=\vec e_y \]

\(x\to y\to z\to x\) の順に回すと、次の軸が出てきます。これは座標軸を右手系（\(x\) から \(y\) へ回す右ねじが \(z\) の向きに進む）に取っているからです。物理では、回転に関わる量（角運動量や力のモーメント）や、磁場から受ける力に外積が現れます。その意味は古典力学と電磁気学のセクションで扱います。

§03

スカラー場とベクトル場

空間の各点 \((x,y,z)\) に、何かの量が1つずつ割り当てられているとき、それを場といいます。割り当てられる量の種類で、場は区別されます。

見た目での区別

  • スカラー場：各点に数が1つ。温度の分布 \(T(x,y,z)\) のようなもので、6章で扱った多変数関数そのものです。
  • ベクトル場：各点に矢印が1本。流れの速度の分布のようなもので、成分ごとに3つの多変数関数を並べて書きます。
\[ \vec F=(F_x,\ F_y,\ F_z) \]

ここで \(F_x,\ F_y,\ F_z\) は、それぞれ \(x,\ y,\ z\) の関数です。

たとえば右の図の \(\vec v=({-}y,x)\) では、点 \((1,0)\) に \((0,1)\)、つまり真上向きの矢印が付いています。点 \((0,1)\) では \(({-}1,0)\) で左向き。原点を中心に、左回りに回る流れになっています。

本当の区別：座標軸を回したとき、どう変わるか

「数か矢印か」は見た目の区別です。物理では、もう一段深い区別を使います。座標軸を回したとき、値がどう変わるかです。

ある点の温度が 20 度なら、座標軸をどう回しても、その点の温度は 20 度のままです。座標軸は人間が勝手に置いたものなので、温度そのものとは関係ありません。

矢印はどうでしょうか。

矢印そのものは同じでも、それを測る軸が回ったので、成分は変わります。どう変わるかは、§01 の「ものさし」で計算できます。回した軸の向きの長さ 1 のベクトルは

\[ \begin{aligned}\vec e_{x'}&=(\cos\alpha,\ \sin\alpha)\\\vec e_{y'}&=({-}\sin\alpha,\ \cos\alpha)\end{aligned} \]

です。新しい成分は、これらとの内積で取り出せます。

軸を回したときの成分の変わり方 \[ \begin{aligned}v_{x'}&=v_x\cos\alpha+v_y\sin\alpha\\v_{y'}&={-}v_x\sin\alpha+v_y\cos\alpha\end{aligned} \]

新しい成分は、元の2つの成分が混ざり合ったものになります。

スカラーとベクトルの定義し直し

スカラー：座標軸を回しても、値が変わらない量。

ベクトル：座標軸を回すと、成分が上の規則で混ざり合う量。

この見方では、「ベクトルの長さ」や「2つのベクトルの内積」も、回しても変わらないのでスカラーです（「まず自力で」とドリルで確かめます）。

まず自力で

上の変わり方の式を使って、座標軸を回してもベクトルの長さが変わらないこと、つまり次の式を確かめてください。

\[ v_{x'}^2+v_{y'}^2=v_x^2+v_y^2 \]
HINT 1

\(v_{x'}^2\) と \(v_{y'}^2\) をそれぞれ展開して足します。\(v_xv_y\) を含む項が打ち消し合うはずです。

1\(v_{x'}^2\) を展開する
なぜ：\((A+B)^2=A^2+2AB+B^2\) で、\(A=v_x\cos\alpha\)、\(B=v_y\sin\alpha\) とします。
\[ v_{x'}^2=(v_x\cos\alpha+v_y\sin\alpha)^2 \]

3つの項を1つずつ計算します。

\[ \begin{aligned}A^2&=v_x^2\cos^2\alpha\\2AB&=2v_xv_y\sin\alpha\cos\alpha\\B^2&=v_y^2\sin^2\alpha\end{aligned} \]

したがって

\[ \begin{aligned}v_{x'}^2&=v_x^2\cos^2\alpha+v_y^2\sin^2\alpha\\&\quad+2v_xv_y\sin\alpha\cos\alpha\end{aligned} \]
2\(v_{y'}^2\) を展開する
なぜ：同じ公式で、今度は \(A={-}v_x\sin\alpha\)、\(B=v_y\cos\alpha\) とします。
\[ v_{y'}^2=({-}v_x\sin\alpha+v_y\cos\alpha)^2 \]

3つの項は次のとおりです。\(A^2\) では2乗でマイナスが消え、\(2AB\) ではマイナスが残ります。

\[ \begin{aligned}A^2&=v_x^2\sin^2\alpha\\2AB&={-}2v_xv_y\sin\alpha\cos\alpha\\B^2&=v_y^2\cos^2\alpha\end{aligned} \]

したがって

\[ \begin{aligned}v_{y'}^2&=v_x^2\sin^2\alpha+v_y^2\cos^2\alpha\\&\quad-2v_xv_y\sin\alpha\cos\alpha\end{aligned} \]
3足して、同じ種類の項をまとめる
なぜ：\(v_x^2\) の項、\(v_y^2\) の項、\(v_xv_y\) の項（交差項）に分けて整理します。

\(v_x^2\) の項は、手順1と2から \(\cos^2\alpha\) と \(\sin^2\alpha\) が1つずつ出てきます。

\[ \begin{aligned}&v_x^2\cos^2\alpha+v_x^2\sin^2\alpha\\&=v_x^2(\cos^2\alpha+\sin^2\alpha)\\&=v_x^2\end{aligned} \]

\(v_y^2\) の項も同じく \(v_y^2(\sin^2\alpha+\cos^2\alpha)=v_y^2\) です。交差項は

\[ \begin{aligned}&2v_xv_y\sin\alpha\cos\alpha\\&-2v_xv_y\sin\alpha\cos\alpha=0\end{aligned} \]

で打ち消し合います。以上をまとめて

\[ v_{x'}^2+v_{y'}^2=v_x^2+v_y^2 \]

成分は変わっても、それを組み合わせた長さは変わりません。変わるもの（成分）と変わらないもの（長さ）を見分けることが、この先の物理で法則を書くときの基本になります。成分の変わり方の式は、9章で「回転を表す行列」として整理し直します。

物理の場は、この区別で分類される

電磁気学や場の量子論に出てくる場は、「回したときの変わり方」で種類が決まります。

種類回したときの変わり方例
スカラー場変わらないヒッグス場（素粒子に質量を与える場）
インフラトン場（宇宙初期にインフレーションを起こしたと考えられている場）
ベクトル場成分がベクトルとして混ざる電場・磁場、ゲージ場（光子など、力を伝える場）
スピノル場ベクトルとも違う変わり方。1回転（360°）させると符号が反転する電子やクォーク（フェルミオン）の場

相対性理論が入ると、回転に「時間と空間を混ぜる変換」も加えて分類しますが、考え方は同じです。スピノル場はこの教材の道具だけでは中身に踏み込めないので、ここでは名前にとどめます。それぞれの場が何を表し、どう振る舞うかは、電磁気学・場の量子論・宇宙論のセクションで扱います。

計算ドリル（§03・全1問）

問1\(\vec v=(3,4)\) とする。座標軸を \(\alpha=90^\circ\) 回したときの成分 \((v_{x'},v_{y'})\) を求め、長さが変わらないことを確かめよ。

自分の答えを出してから
HINT 1

\(\cos90^\circ=0\)、\(\sin90^\circ=1\) を変わり方の式に入れます。

本文の変わり方の式は次のとおりです。

\[ v_{x'}=v_x\cos\alpha+v_y\sin\alpha \] \[ \begin{aligned}v_{y'}&={-}v_x\sin\alpha\\&\quad+v_y\cos\alpha\end{aligned} \]

ここに \(v_x=3\)、\(v_y=4\)、\(\cos90^\circ=0\)、\(\sin90^\circ=1\) を入れます。

\[ \begin{aligned}v_{x'}&=3\cdot0+4\cdot1\\&=4\end{aligned} \] \[ \begin{aligned}v_{y'}&={-}3\cdot1+4\cdot0\\&={-}3\end{aligned} \]

新しい成分は \((4,{-}3)\) です。長さはどちらも \(\sqrt{9+16}=5\) で変わりません。

\(x'\) 軸は元の \(y\) 軸の向き、\(y'\) 軸は元の \(x\) 軸の逆向きになったので、成分が入れ替わり、片方の符号が変わりました。図を描いて確かめてみてください。式が合っているかは、特別な角度（0°、90°）で確かめるのが手早い検算です。

§04

線積分 — 道に沿って足し上げる

7章では、スカラー場を面積や体積の上で足し上げました。ベクトル場では、道に沿って足し上げることがよく必要になります。矢印の場の中を、ある道に沿って進むとき、場がどれだけ「後押し」したかを合計したい、という場面です。

足し上げる道に名前を付けて、C と呼びます（図の緑の曲線）。道 C の上で、小さく進んだ移動を \(d\vec r=(dx,dy)\) とします。この区間で足すべき量は、「\(\vec F\) の道に沿った成分」×「進んだ長さ」です。これは §01 の内積そのものです。

\[ \vec F\cdot d\vec r=F_x\,dx+F_y\,dy \]

右辺の形に見覚えがあるはずです。この右辺は、6-2 で完全微分かどうかを判定した式 \(A\,dx+B\,dy\) と同じ形です。\(A\) にあたるのが \(F_x\)、\(B\) にあたるのが \(F_y\) です。

道を媒介変数で表す

実際に計算するには、道の上の点を1つの変数 \(t\) で表します。\(t\) を動かすと点が道の上を A から B まで動くように、\(x(t),\ y(t)\) を決めます。

すると \(dx=\dfrac{dx}{dt}\,dt\)、\(dy=\dfrac{dy}{dt}\,dt\) なので、1変数の積分になります。

線積分 \[ \begin{aligned}&\int_C\vec F\cdot d\vec r\\&=\int_{t_A}^{t_B}\Big(F_x\frac{dx}{dt}+F_y\frac{dy}{dt}\Big)dt\end{aligned} \]

\(F_x,\ F_y\) の中の \(x,\ y\) にも \(x(t),\ y(t)\) を入れて、すべて \(t\) の式にしてから積分します。3次元なら \(F_z\frac{dz}{dt}\) の項が加わるだけです。

記号 \(\int_C\) の読み方

積分記号の下に付いた \(C\) は、どの道に沿って足し上げるかを表します。1変数の積分 \(\int_a^b\) では「どこからどこまで」を上下に書けば済みましたが、平面や空間では、同じ2点を結ぶ道がいくらでもあります。そこで、始点と終点だけでなく道そのものに名前（ここでは \(C\)）を付けて、積分記号の下に書きます。

道には向きがあります。\(C\) は A から B へ進む道です。同じ道を B から A へ逆向きにたどると、各区間の \(d\vec r\) の向きがすべて逆になるので、線積分の値は符号だけが反転します。媒介変数で書いたときは、\(t\) の積分の上限と下限が入れ替わることにあたります。

同じ2点を、違う道で結ぶ

A \(=(1,0)\) から B \(=(0,1)\) まで、2本の道で線積分を比べます。道1はまっすぐな線分、道2は原点を中心とする半径 1 の円弧です。

右の場 \(\vec F=(y,{-}x)\) で、道2を計算してみます。円弧は \(x=\cos t,\ y=\sin t\)（\(t\) は \(0\) から \(\frac{\pi}{2}\) まで）と表せます。

\[ \frac{dx}{dt}={-}\sin t,\qquad \frac{dy}{dt}=\cos t \]

\(F_x=y=\sin t\)、\(F_y={-}x={-}\cos t\) なので、被積分関数は

\[ \sin t\cdot({-}\sin t)+({-}\cos t)\cdot\cos t={-}1 \]

です。\({-}1\) を \(0\) から \(\frac{\pi}{2}\) まで積分して、道2の値は \({-}\frac{\pi}{2}\) です。

まず自力で

同じ場 \(\vec F=(y,{-}x)\) で、道1（A \(=(1,0)\) から B \(=(0,1)\) への線分）の線積分を計算し、道2の値 \({-}\frac{\pi}{2}\) と比べてください。

HINT 1

線分は \(x=1-t,\ y=t\)（\(t\) は \(0\) から \(1\) まで）と表せます。\(t=0\) で A、\(t=1\) で B になっていることを確かめてください。

1道を \(t\) で表す
なぜ：線積分を計算するには、道の上の点を \(t\) の式で書く必要があります。

A \(=(1,0)\) から B \(=(0,1)\) へまっすぐ進むとき、進む向きと距離を表すベクトルは「B − A」です。

\[ \mathrm B-\mathrm A=({-}1,\ 1) \]

A から出発して、この矢印の \(t\) 倍だけ進んだ点を考えます。\(t\) を \(0\) から \(1\) まで動かすと、点は A から B まで線分の上を動きます。

\[ \begin{aligned}(x,y)&=(1,0)+t({-}1,1)\\&=(1-t,\ t)\end{aligned} \]

したがって \(x=1-t\)、\(y=t\) です。\(t=0\) で \((1,0)\)＝A、\(t=1\) で \((0,1)\)＝B になっていること、どの \(t\) でも \(x+y=1\)（A と B を通る直線の上）であることも確かめられます。

2微分する
なぜ：被積分関数に \(\dfrac{dx}{dt}\) と \(\dfrac{dy}{dt}\) が必要です。
\[ \frac{dx}{dt}={-}1,\qquad \frac{dy}{dt}=1 \]
3場を \(t\) で書く
なぜ：道の上の点では \(x=1-t\)、\(y=t\) なので、場の成分 \(F_x=y\)、\(F_y={-}x\) の \(x,\ y\) にこれを入れると、道の上での場の値が \(t\) の式になります。

\(F_x=t\)、\(F_y={-}(1-t)\) です。

4被積分関数を作る
なぜ：\(F_x\dfrac{dx}{dt}+F_y\dfrac{dy}{dt}\) です。
\[ t\cdot({-}1)-(1-t)\cdot1={-}1 \]
5積分する
なぜ：\({-}1\) を \(0\) から \(1\) まで積分します。

道1の値は \({-}1\) です。道2の \({-}\frac{\pi}{2}\approx{-}1.57\) とは違います。

同じ2点を結んでも、道によって値が変わりました。道1より道2のほうが長く、しかもこの場は回る流れなので、ずっと向かい風を受け続けたことになります。6-2 で \(y\,dx-x\,dy\) は完全微分でないと判定しました。完全微分でないことと、道によって値が変わることは、同じ事実の2つの顔です。

道によらない場合

左の場 \(\vec F=(2xy,x^2)\) はどうでしょうか。6-2 で、\(2xy\,dx+x^2\,dy\) は完全微分で、\(f=x^2y\) の全微分になっていることを確かめました。

\[ \vec F\cdot d\vec r=df \]

道に沿って \(df\) を足し上げると、途中の細かい変化が次々に打ち消し合い、終点での値と始点での値の差だけが残ります。1変数の積分で \(\int_a^bF'(x)\,dx=F(b)-F(a)\) となったのと同じ仕組みです。

道によらない線積分

\(\vec F\cdot d\vec r\) がある関数 \(f\) の全微分 \(df\) になっているとき

\[ \int_C\vec F\cdot d\vec r=f(\mathrm B)-f(\mathrm A) \]

で、道 C の選び方によりません。このとき \(\vec F=\Big(\dfrac{\partial f}{\partial x},\dfrac{\partial f}{\partial y}\Big)\) です。

「偏微分を並べた矢印」が、場として現れた

\(\vec F=\Big(\dfrac{\partial f}{\partial x},\dfrac{\partial f}{\partial y}\Big)\) は、6-2 の未定乗数法で「等高線に垂直な向き」として使った、あの矢印です。スカラー場 \(f\) から、各点に矢印を持つベクトル場が1つ作られています。

この操作を grad（勾配）と呼び、次の 8-2 で主役として扱います。物理では、\(f\) にあたるものがポテンシャル、道によらない力が保存力です。その意味は古典力学と電磁気学のセクションで扱います。

1周まわって戻る道

始点と終点が同じ道（閉じた道）の線積分を、\(\oint_C\vec F\cdot d\vec r\) と書きます。道によらない場なら、始点と終点の差は 0 なので、1周の線積分は必ず 0 です。

回る流れ \(\vec F=(y,{-}x)\) では、1周の値は 0 になりません。1周して値が残ることは、場が「回っている」ことの印です。この「回り具合」を各点で測る道具が、8-3 の rot です。

計算ドリル（§04・全2問）

問1\(\vec F=(2xy,x^2)\) について、道1（\(x=1-t,\ y=t\)、\(t\) は \(0\) から \(1\) まで）の線積分を直接計算し、\(f(\mathrm B)-f(\mathrm A)\) と一致することを確かめよ。ただし \(f=x^2y\)、A \(=(1,0)\)、B \(=(0,1)\)。

自分の答えを出してから
HINT 1

\(F_x=2(1-t)t\)、\(F_y=(1-t)^2\)、\(\dfrac{dx}{dt}={-}1\)、\(\dfrac{dy}{dt}=1\) です。

被積分関数は

\[ {-}2(1-t)t+(1-t)^2 \]

展開すると \(3t^2-4t+1\) です。これを \(0\) から \(1\) まで積分すると

\[ \Big[t^3-2t^2+t\Big]_0^1=0 \]

一方、\(f(\mathrm B)=0^2\cdot1=0\)、\(f(\mathrm A)=1^2\cdot0=0\) なので \(f(\mathrm B)-f(\mathrm A)=0\)。一致します。

値が 0 になったのは、A も B も \(f=x^2y\) が 0 になる座標軸の上にあるからで、場が弱いからではありません。途中の被積分関数 \(3t^2-4t+1\) は正にも負にもなっていて、行きの後押しと帰りの向かい風がちょうど打ち消し合ったのです。円弧の道2で計算しても、同じ 0 になります。

問2口頭試問形式：次の3つを、公式を見ずに自分の言葉で説明せよ。
①内積が「成分を取り出す操作」だというのはどういうことか。
②スカラー場とベクトル場を、座標軸を回したときの変わり方で区別せよ。
③線積分が道によらないのは、どんな場のときか。それは 6-2 の何とつながっているか。

自分の答えを出してから

① 長さ 1 のベクトル \(\vec e\) との内積 \(\vec e\cdot\vec b\) は、\(|\vec b|\cos\theta\)、つまり \(\vec b\) の \(\vec e\) 方向の成分になる。好きな向きにものさしを当てて、その向きの成分を読むことにあたる。

② スカラー場は、座標軸を回しても各点の値が変わらない。ベクトル場は、各点の矢印そのものは変わらないが、成分が回転の角度に応じて混ざり合って変わる。ただし長さや内積のように、成分から作っても回して変わらない量はスカラーになる。

③ \(\vec F\cdot d\vec r=F_x\,dx+F_y\,dy\) が、ある関数 \(f\) の全微分になっている場。このとき線積分は \(f(\mathrm B)-f(\mathrm A)\) だけで決まる。6-2 の完全微分の条件 \(\dfrac{\partial F_x}{\partial y}=\dfrac{\partial F_y}{\partial x}\) を満たすかどうかで判定できる。

この3つが澱みなく言えれば、この記事は通過です。特に③は、8-2 の grad と 8-3 の rot の両方につながる要の結果なので、6-2 のノートと並べて見直してください。
