8-3　div と rot湧き出しと回り具合を、各点で測る

8-2 の grad は、スカラー場からベクトル場を作る操作でした。この記事では向きを変えて、ベクトル場の性質を各点で測る操作を2つ作ります。

1つは、流れがその点から湧き出しているかを測る div。もう1つは、流れがその点のまわりでどれだけ回っているかを測る rot です。どちらも「小さな箱」「小さな輪」で流れを調べ、その大きさで割るという同じ発想から生まれます。

電磁気学の基本法則は、この div と rot で書かれています。その準備として、8-1 で先送りした面を通り抜ける量から始めます。

読み方：解答は必ず閉じたまま、紙で挑戦してください。

§01

面を通り抜ける量（面積分）

ベクトル場を、水の流れの速さと向きだと思って読みます。流れの中に、水をさえぎらない網のような枠を置いたとき、枠を通り抜ける水の量はどれだけでしょうか。

同じ大きさの枠でも、傾けると通り抜ける量は減ります。流れの側から見ると、枠が斜めになって幅が狭く見えるからです。この「見かけの幅」は、枠を傾けた角度を \(\theta\) とすると、元の幅の \(\cos\theta\) 倍です。

面の向きを、垂直な矢印で表す

枠の傾きを表すために、面に垂直で長さ 1 のベクトル \(\vec n\) を使います。これを法線ベクトルといいます。8-1 の外積で、面の向きを「面に垂直な矢印」で表したのと同じ考え方です。

面積 \(dA\) の小さな面を通り抜ける量は、「流れの速さ × 見かけの面積」です。流れ \(\vec F\) と \(\vec n\) のなす角を \(\theta\) とすると、見かけの面積は \(dA\cos\theta\) なので

\[ |\vec F|\,dA\cos\theta=(\vec F\cdot\vec n)\,dA \]

となります。右辺の \(\vec F\cdot\vec n\) は、8-1 のものさしで取り出した「流れの、面に垂直な成分」です。面に沿った成分は、面をかすめるだけで通り抜けません。

面積分（流束）

面 \(S\) 全体を通り抜ける量は、小さな面ごとの量を足し上げたものです。

\[ \Phi=\iint_S\vec F\cdot\vec n\,dA \]

これを \(\vec F\) の \(S\) を通る流束といい、この形の積分を面積分といいます。7章の重積分で、足し上げる中身が「面に垂直な成分」になったものです。

\(\vec n\) には向きが2つ（表と裏）あります。\(\vec n\) の向きに通り抜ける量をプラスと数えます。箱のように閉じた面では、外向きを \(\vec n\) とするのが決まりです。

まず自力で

一様な流れ \(\vec F=(3,0,0)\) の中に、1辺 2 の正方形の枠を置きます。(a) 枠が \(yz\) 平面に平行（\(\vec n=\vec e_x\)）のとき、(b) \(\vec n=(\cos60^\circ,\ \sin60^\circ,\ 0)\) の向きに傾けたとき、それぞれの流束を求めてください。

HINT 1

流れが一様で枠が平らなので、\(\vec F\cdot\vec n\) はどこでも同じです。面積分は「\(\vec F\cdot\vec n\) × 面積」になります。

1面積を求める
なぜ：\(\vec F\cdot\vec n\) が一定なので、面積を掛けるだけです。

1辺 2 の正方形なので、面積は 4 です。

2(a) 垂直な成分を取り出す
なぜ：\(\vec n=\vec e_x\) との内積は \(F_x\) です。
\[ \begin{aligned}\Phi&=(\vec F\cdot\vec e_x)\times4\\&=3\times4=12\end{aligned} \]
3(b) 傾けた場合
なぜ：内積を成分で計算します。
\[ \begin{aligned}\vec F\cdot\vec n&=3\cos60^\circ+0+0\\&=\frac32\end{aligned} \]

流束は \(\dfrac32\times4=6\) で、(a) の半分です。

枠を \(60^\circ\) 傾けると、流れから見た幅は \(\cos60^\circ=\frac12\) 倍になり、通り抜ける量も半分になりました。図で数えた「線の本数が減る」ことが、内積 \(\vec F\cdot\vec n\) の \(\cos\theta\) として式に現れています。

計算ドリル（§01・全1問）

問1一様な流れ \(\vec F=(1,2,3)\) の中に、1辺 1 の正方形の枠を置く。枠が (a) \(xy\) 平面に平行（\(\vec n=\vec e_z\)）のとき、(b) \(xz\) 平面に平行（\(\vec n=\vec e_y\)）のとき、それぞれの流束を求めよ。

自分の答えを出してから

面積は 1 なので、流束は \(\vec F\cdot\vec n\) そのものです。

(a) \(\vec F\cdot\vec e_z=F_z=3\)

(b) \(\vec F\cdot\vec e_y=F_y=2\)

座標平面に平行な面では、法線ベクトルが基本ベクトルになり、流束は流れの1つの成分だけで決まります。\(xy\) 平面に平行な面を通り抜けるのは \(z\) 方向の流れだけ、というのは図で考えても自然です。この性質を、§02 の小さな箱で使います。

この記事の到達目標
  • 面を通り抜ける量を、法線ベクトルとの内積で計算できる
  • div を小さな箱から導き、計算し、意味を説明できる
  • rot を小さな輪から導き、計算し、意味を説明できる
  • \(\nabla\) を使って div・rot・ラプラシアンを書ける
  • \(\mathrm{rot}\,\mathrm{grad}\,f=\vec 0\) を、偏微分の順序交換から示せる
前提として使うもの
  • 8-1：内積、外積、線積分
  • 8-2：grad、\(\nabla\)
  • 7章：重積分
  • 6-1・6-2：偏微分、偏微分の順序交換、完全微分の条件
§02

div：湧き出しを測る

流れの中のある点が、水の湧き出し口になっているかどうかを調べたいとします。その点を囲む小さな箱を考え、箱から出ていく量と入ってくる量の差を見ます。出ていく量のほうが多ければ、箱の中で水が湧いています。

箱の面ごとに数える

2次元で、横 \(dx\)、縦 \(dy\) の小さな箱を考えます。§01 のドリルのとおり、左右の面を通り抜けるのは \(x\) 方向の流れ \(F_x\) だけです。

  • 右の面（長さ \(dy\)）から出ていく量：\(F_x(x+dx)\,dy\)
  • 左の面から入ってくる量：\(F_x(x)\,dy\)

出ていく量から入ってくる量を引いた差を、次のように変形します。

\[ \begin{aligned}&\big(F_x(x+dx)-F_x(x)\big)\,dy\\&=\frac{F_x(x+dx)-F_x(x)}{dx}\,dx\,dy\\&\approx\frac{\partial F_x}{\partial x}\,dx\,dy\end{aligned} \]

2行目では、\(dx\) で割って \(dx\) を掛けています（値は変わりません）。こうすると、分数の部分が「\(y\) を止めて \(x\) だけを \(dx\) 動かしたときの、\(F_x\) の変化の割合」になります。\(dx\) を小さくすると、6-1 の偏微分の定義から、この割合は \(\dfrac{\partial F_x}{\partial x}\) に近づきます。これが3行目です。

上下の面も同じで、差は \(\dfrac{\partial F_y}{\partial y}\,dx\,dy\) です。合計を箱の面積 \(dx\,dy\) で割ると、箱の大きさによらない量になります。

div（発散） \[ \mathrm{div}\,\vec F=\frac{\partial F_x}{\partial x}+\frac{\partial F_y}{\partial y}+\frac{\partial F_z}{\partial z} \]

3次元では、前後の面から \(z\) の項が加わります。div は「その点のまわりの小さな箱から、単位体積あたりどれだけ出ていくか」を表すスカラーです。

名前の div は、英語の divergence（ダイバージェンス）の略で、「広がって散っていくこと」という意味です。日本語では発散と訳します。流れがその点から四方へ散っていく度合い、という名前の由来そのままの量です。

  • \(\mathrm{div}\,\vec F>0\)：湧き出している
  • \(\mathrm{div}\,\vec F<0\)：吸い込まれている
  • \(\mathrm{div}\,\vec F=0\)：入った分だけ出ていく

図の2つを計算で確かめます。左の \(\vec F=(x,y)\) では \(\dfrac{\partial x}{\partial x}+\dfrac{\partial y}{\partial y}=1+1=2\)。右の \(\vec F=({-}y,x)\) では、\(F_x={-}y\) は \(x\) を含まず、\(F_y=x\) は \(y\) を含まないので、div は 0 です。

物理での div
  • 電場の湧き出し口は電荷：電場の div は、その場所の電荷の量に比例します。電荷のない所では、電場の div は 0 です。
  • 磁場には湧き出し口がない：磁場の div はどこでも 0 です。N 極だけ、S 極だけの磁石が見つかっていないことに対応します。
  • 水はほとんど縮まない：水の流れでは、ある場所に入った分はそのまま出ていくので、速度の div はほぼ 0 です。

電場と磁場の div の意味は、電磁気学のセクションで扱います。

まず自力で

\(\vec F=(x^2,\ xy,\ z)\) の div を求め、点 \((1,0,0)\) での値を答えてください。

HINT 1

\(F_x\) は \(x\) で、\(F_y\) は \(y\) で、\(F_z\) は \(z\) で、それぞれ偏微分して足します。組み合わせを取り違えないように。

13つの偏微分
なぜ：div は「自分と同じ向きの変数」で偏微分したものの和です。
\[ \begin{aligned}\frac{\partial F_x}{\partial x}&=2x\\\frac{\partial F_y}{\partial y}&=x\\\frac{\partial F_z}{\partial z}&=1\end{aligned} \]
2足す
なぜ：定義どおりです。
\[ \mathrm{div}\,\vec F=3x+1 \]

点 \((1,0,0)\) では \(4\) です。

div の値は場所によって変わります。この場では \(x\) が大きい所ほど強く湧き出し、\(x<{-}\frac13\) では吸い込みになります。よくある間違いは、\(F_y=xy\) を \(x\) で偏微分してしまうことです。div で使うのは、成分と同じ向きの偏微分だけです。

計算ドリル（§02・全1問）

問1\(\vec F=(3x,\ {-}y,\ {-}2z)\) の div を求めよ。この流れは湧き出しているか。

自分の答えを出してから

3つの偏微分は \(3\)、\({-}1\)、\({-}2\) なので

\[ \begin{aligned}\mathrm{div}\,\vec F&=3-1-2\\&=0\end{aligned} \]

どこでも div は 0 で、湧き出しも吸い込みもありません。

\(x\) 方向には広がっていく流れですが、そのぶん \(y\) 方向と \(z\) 方向に縮んでいて、差し引きがちょうど 0 になっています。どれか1方向だけを見て「湧き出している」と判断してはいけないという例です。縮まない水の流れは、こうした形をしています。

§03

rot：回り具合を測る

8-1 §04 で、回る流れ \((y,{-}x)\) では1周の線積分が 0 にならないことを見ました。この「1周して残る量」を、各点ごとの回り具合として測ります。その点のまわりに小さな輪を置き、輪を1周する線積分を調べます。

辺ごとに数える

横 \(dx\)、縦 \(dy\) の小さな正方形を、反時計回りに1周します。各辺で足すのは、8-1 の線積分と同じく「場の辺に沿った成分 × 辺の長さ」です。

  • 下の辺（右向き）：\(F_x(y)\,dx\)　上の辺（左向き）：\({-}F_x(y+dy)\,dx\)
  • 右の辺（上向き）：\(F_y(x+dx)\,dy\)　左の辺（下向き）：\({-}F_y(x)\,dy\)

上下の辺を合わせた量も、§02 と同じく \(dy\) で割って \(dy\) を掛ける変形をします。

\[ \begin{aligned}&{-}\big(F_x(y+dy)-F_x(y)\big)\,dx\\&={-}\frac{F_x(y+dy)-F_x(y)}{dy}\,dx\,dy\\&\approx{-}\frac{\partial F_x}{\partial y}\,dx\,dy\end{aligned} \]

分数の部分は、\(x\) を止めて \(y\) だけを \(dy\) 動かしたときの \(F_x\) の変化の割合で、\(dy\) を小さくすると \(\dfrac{\partial F_x}{\partial y}\) に近づきます。左右の辺も同じ変形で

\[ \begin{aligned}&\big(F_y(x+dx)-F_y(x)\big)\,dy\\&\approx\frac{\partial F_y}{\partial x}\,dx\,dy\end{aligned} \]

です。合計を面積 \(dx\,dy\) で割ると

\[ \frac{\partial F_y}{\partial x}-\frac{\partial F_x}{\partial y} \]

が得られます。これが、\(xy\) 平面内での回り具合です。

6-2 の完全微分の条件が、ここに現れた

この式は、6-2 の完全微分の条件 \(\dfrac{\partial F_x}{\partial y}=\dfrac{\partial F_y}{\partial x}\) の左辺と右辺の差そのものです。

完全微分の条件を満たす場（8-2 のポテンシャルを持つ場）では、この差が 0、つまりどこも回っていません。だから1周の線積分が 0 になり、線積分が道によらなかったのです。6-2・8-1・8-2 の結果が、「回り具合が 0」という1つの事実にまとまりました。

3次元の rot

3次元では、輪を \(xy\) 平面に置けば \(z\) 軸まわりの回り具合、\(yz\) 平面なら \(x\) 軸まわり、\(zx\) 平面なら \(y\) 軸まわりが測れます。3つを並べたベクトルが rot です。

rot（回転） \[ \begin{aligned}(\mathrm{rot}\,\vec F)_x&=\frac{\partial F_z}{\partial y}-\frac{\partial F_y}{\partial z}\\(\mathrm{rot}\,\vec F)_y&=\frac{\partial F_x}{\partial z}-\frac{\partial F_z}{\partial x}\\(\mathrm{rot}\,\vec F)_z&=\frac{\partial F_y}{\partial x}-\frac{\partial F_x}{\partial y}\end{aligned} \]

覚え方は 8-1 の外積と同じで、\(z\) 成分から始めて文字を \(x\to y\to z\to x\) と1つずつずらします。rot はベクトルで、向きは回転の軸（右ねじが進む向き）、長さは回り具合の強さです。

名前の rot は、英語の rotation（ローテーション）の略で、「回転」という意味です。英語の本では同じものを curl（カール、「巻く・渦を巻く」）と呼び、\(\mathrm{curl}\,\vec F\) と書くことも多いので、見かけたら rot と同じものだと読み替えてください。

右の図は、rot の意外な一面です。流れの線がまっすぐでも、場所によって速さが違えば、小さな水車は回ります。逆に、竜巻のように大きく回っている流れでも、回り具合が 0 の場所もあります。rot が測るのは「流れの線が曲がっているか」ではなく、「その点に置いた小さな水車が回るか」です。

物理での rot
  • 電流のまわりに磁場が回る：磁場の rot は、その場所の電流に比例します。
  • 変化する磁場のまわりに電場が回る：8-2 §04 で触れた、コイルに磁石を出し入れすると電流が流れる現象です。電場の rot が 0 でなくなるので、電場は電位だけでは表せなくなります。

電場と磁場の rot の意味は、電磁気学のセクションで扱います。

まず自力で

回る流れ \(\vec F=({-}y,\ x,\ 0)\) について、(a) rot を求めてください。(b) 原点を中心とする半径 \(R\) の円を反時計回りに1周する線積分を計算し、(c)「rot の \(z\) 成分 × 円の面積」と比べてください。

HINT 1

(b) 円は \(x=R\cos t,\ y=R\sin t\)（\(t\) は \(0\) から \(2\pi\) まで）と表せます。8-1 §04 と同じ手順です。

1(a) rot を計算する
なぜ：\(F_z=0\) で、\(F_x,\ F_y\) は \(z\) を含まないので、\(x,\ y\) 成分は 0 です。
\[ \begin{aligned}(\mathrm{rot}\,\vec F)_z&=\frac{\partial x}{\partial x}-\frac{\partial({-}y)}{\partial y}\\&=2\end{aligned} \]

\(\mathrm{rot}\,\vec F=(0,0,2)\) で、どの点でも同じです。

2(b) 円を媒介変数で表す
なぜ：線積分の計算に \(\dfrac{dx}{dt}\)、\(\dfrac{dy}{dt}\) が必要です。
\[ \begin{aligned}\frac{dx}{dt}&={-}R\sin t\\\frac{dy}{dt}&=R\cos t\end{aligned} \]
3被積分関数を作る
なぜ：\(F_x={-}R\sin t\)、\(F_y=R\cos t\) を入れます。
\[ \begin{aligned}&({-}R\sin t)({-}R\sin t)\\&\quad+(R\cos t)(R\cos t)\\&=R^2\end{aligned} \]

\(R^2\) を \(0\) から \(2\pi\) まで積分して、1周の線積分は \(2\pi R^2\) です。

4(c) rot × 面積と比べる
なぜ：rot は「単位面積あたりの1周の線積分」でした。
\[ 2\times\pi R^2=2\pi R^2 \]

大きな円の1周の線積分が、「rot × 面積」とぴったり一致しました。rot は小さな輪で定義したのに、大きな円でも成り立っています。円の中を小さな輪で埋め尽くすと、隣り合う輪の辺どうしが打ち消し合い、外周だけが残るからです。これが次の 8-4 で扱うストークスの定理です。

計算ドリル（§03・全1問）

問1次の場の rot の \(z\) 成分を求めよ。
(a) ずれる流れ \(\vec F=(y+1,\ 0,\ 0)\)
(b) 8-2 §04 の \(\vec F=(2xy+1,\ x^2,\ 0)\)

自分の答えを出してから

(a) \(F_y=0\)、\(F_x=y+1\) なので

\[ \begin{aligned}(\mathrm{rot}\,\vec F)_z&=0-1\\&={-}1\end{aligned} \]

負なので右回りです（上の図の右）。

(b) \(\dfrac{\partial F_y}{\partial x}=2x\)、\(\dfrac{\partial F_x}{\partial y}=2x\) なので

\[ \begin{aligned}(\mathrm{rot}\,\vec F)_z&=2x-2x\\&=0\end{aligned} \]

(b) は 8-2 でポテンシャル \(f=x^2y+x\) を持つと確かめた場です。ポテンシャルを持つ場は回らないことが、計算でも確かめられました。一般に成り立つことを §04 で示します。

§04

ナブラでまとめる

8-2 で、偏微分の操作を並べた記号 \(\nabla=\Big(\dfrac{\partial}{\partial x},\dfrac{\partial}{\partial y},\dfrac{\partial}{\partial z}\Big)\) を導入し、\(\mathrm{grad}\,f=\nabla f\) と書きました。この \(\nabla\) をベクトルのように扱うと、div と rot もまとめて書けます。

\(\nabla\) による表し方 \[ \begin{aligned}\mathrm{grad}\,f&=\nabla f\\\mathrm{div}\,\vec F&=\nabla\cdot\vec F\\\mathrm{rot}\,\vec F&=\nabla\times\vec F\end{aligned} \]

\(\nabla\cdot\vec F\) は、\(\nabla\) と \(\vec F\) の「内積」を成分で書いたもの（\(\frac{\partial}{\partial x}\) と \(F_x\) を組にして足す）で、div の定義と一致します。\(\nabla\times\vec F\) は「外積」の成分の式に \(\nabla\) を入れたもので、rot の定義と一致します。

物理の本では、div と rot より \(\nabla\cdot\) と \(\nabla\times\) のほうがよく使われます。「湧き出しは内積、回り具合は外積」と、8-1 の2つの積に対応づけて覚えられます。

grad の場は回らない

8-2 の予告を確かめます。スカラー場 \(f\) の grad の rot を計算すると、\(z\) 成分は

\[ \frac{\partial}{\partial x}\Big(\frac{\partial f}{\partial y}\Big)-\frac{\partial}{\partial y}\Big(\frac{\partial f}{\partial x}\Big) \]

です。これは同じ2回の偏微分を順序を変えて引いたもので、6-2 §01 の順序交換から 0 になります。\(x,\ y\) 成分も同じです。

2つの恒等式 \[ \mathrm{rot}\,\mathrm{grad}\,f=\vec 0,\qquad \mathrm{div}\,\mathrm{rot}\,\vec F=0 \]

1つ目は「ポテンシャルを持つ場は回らない」。2つ目も同じく、展開すると順序だけが違う2回の偏微分が組になって打ち消し合います。「回っているだけの場からは湧き出さない」と読めます。

まず自力で

\(f=x^2y+yz\) について、\(\mathrm{grad}\,f\) を求め、その rot が \(\vec 0\) になることを、3成分すべて計算して確かめてください。

HINT 1

\(\mathrm{grad}\,f=(2xy,\ x^2+z,\ y)\) です。これを \(\vec F\) として、rot の3つの成分の式に入れます。

1grad を求める
なぜ：rot を取る相手のベクトル場です。
\[ \mathrm{grad}\,f=(2xy,\ x^2+z,\ y) \]
2\(x\) 成分
なぜ：\(\dfrac{\partial F_z}{\partial y}-\dfrac{\partial F_y}{\partial z}\) です。
\[ \begin{aligned}&\frac{\partial y}{\partial y}-\frac{\partial(x^2+z)}{\partial z}\\&=1-1=0\end{aligned} \]
3\(y\) 成分
なぜ：\(\dfrac{\partial F_x}{\partial z}-\dfrac{\partial F_z}{\partial x}\) です。
\[ \begin{aligned}&\frac{\partial(2xy)}{\partial z}-\frac{\partial y}{\partial x}\\&=0-0=0\end{aligned} \]
4\(z\) 成分
なぜ：\(\dfrac{\partial F_y}{\partial x}-\dfrac{\partial F_x}{\partial y}\) です。
\[ \begin{aligned}&\frac{\partial(x^2+z)}{\partial x}-\frac{\partial(2xy)}{\partial y}\\&=2x-2x=0\end{aligned} \]

3成分とも 0 になりました。各成分で引き算している2つの項は、どちらも \(f\) を同じ2つの変数で1回ずつ偏微分したもので、順序が違うだけです。たとえば \(z\) 成分の \(2x\) は、\(f\) を \(x\) と \(y\) で1回ずつ偏微分したもの。6-2 の順序交換が、ここでも効いています。

ラプラシアン

grad と div を続けて使うと、スカラー場からスカラー場を作る操作ができます。

ラプラシアン \[ \mathrm{div}\,\mathrm{grad}\,f=\frac{\partial^2f}{\partial x^2}+\frac{\partial^2f}{\partial y^2}+\frac{\partial^2f}{\partial z^2} \]

\(\nabla\cdot\nabla f\) なので \(\nabla^2f\) と書き（\(\Delta f\) と書く本もあります）、ラプラシアンと呼びます。

意味は、grad（坂の向き）の湧き出しです。坂の矢印がその点から外向きに広がっていれば、その点はまわりより低い谷で、ラプラシアンは正になります。つまりラプラシアンは、その点の値が、まわりの平均と比べてどれだけ低いか（高いか）を測ります。

物理の基本方程式に現れる

「まわりとの差」を測る量なので、場所ごとの違いがならされていく現象や、違いが伝わっていく現象の方程式に、決まって現れます。

  • 電磁気学：電荷の分布から電位を決める方程式
  • 波：音や光などの波が伝わる様子を表す方程式
  • 量子力学：粒子の状態を決めるシュレーディンガー方程式

さらに電磁気学の基本法則（マクスウェル方程式）は、言葉にすると「電場の湧き出し口は電荷」「磁場には湧き出し口がない」「変化する磁場のまわりに電場が回る」「電流と変化する電場のまわりに磁場が回る」の4つで、すべて div と rot で書かれています。それぞれの方程式の形と意味は、電磁気学・量子力学のセクションで扱います。

計算ドリル（§04・全2問）

問1\(f=x^2+y^2+z^2\) のラプラシアンを求めよ。また、原点はまわりより高いか低いか。

自分の答えを出してから

2回の偏微分はどれも 2 なので

\[ \begin{aligned}\nabla^2f&=2+2+2\\&=6\end{aligned} \]

正なので、どの点もまわりの平均より低くなっています。原点では \(f=0\) で、まわりはすべて正なので、確かにまわりより低い谷の底です。

\(f\) は原点からの距離の2乗で、8-2 のすり鉢を3次元にしたものです。grad \((2x,2y,2z)\) は原点から外向きに広がっていて、その湧き出し（div）が 6 です。「谷ならラプラシアンは正」を、具体例で確かめてください。

問2口頭試問形式：次の3つを、公式を見ずに自分の言葉で説明せよ。
①div は何を測る量か。どうやって偏微分から作られるか。
②rot は何を測る量か。まっすぐな流れでも rot が 0 でないことがあるのはなぜか。
③\(\mathrm{rot}\,\mathrm{grad}\,f=\vec 0\) となるのはなぜか。

自分の答えを出してから

① その点のまわりの小さな箱から、単位体積あたりどれだけ出ていくか（湧き出し）。向かい合う面で出ていく量と入ってくる量の差を取ると、その差が偏微分 \(\frac{\partial F_x}{\partial x}\) などになり、3方向を足して箱の大きさで割ると div になる。

② その点のまわりの小さな輪を1周する線積分を、面積で割ったもの（回り具合）。小さな水車が回るかどうかにあたる。まっすぐな流れでも、場所によって速さが違えば、水車の片側が強く押されて回る。

③ rot の各成分は、\(f\) を同じ2つの変数で1回ずつ偏微分したものを、順序を変えて引いた形になる。偏微分は順序を入れ替えても同じなので、差は 0。「ポテンシャルを持つ場は回らない」ということ。

この3つが澱みなく言えれば、この記事は通過です。①と②は「小さな箱」「小さな輪」の図を描きながら説明できるか確かめてください。8-4 は、その箱と輪を積み上げる話です。

次節（8-4 ガウスの定理とストークスの定理）への接続

この記事では、div を小さな箱で、rot を小さな輪で定義しました。次の 8-4 では、その小さな箱や輪を積み上げて、大きな立体や大きな面にします。

隣り合う箱では、共有する面を通る量が、片方からは「出ていく」、もう片方からは「入ってくる」として打ち消し合います。すると、中の箱の湧き出しを全部足したものが、外側の面を通り抜ける量に等しくなります。輪についても同じことが起こります。

8-4 で扱う問い（予習用）
  • 小さな箱の湧き出しを全部足すと、何になるのか
  • 小さな輪の回り具合を全部足すと、何になるのか
  • 隣り合う箱や輪の間で、何が打ち消し合うのか
  • 電磁気学の法則は、微分の形と積分の形でどう書き換えられるのか

鍵となる一言：§03 の「まず自力で」で、大きな円の1周の線積分が「rot × 面積」とぴったり一致しました。これは偶然ではありません。その理由を示すのが、ストークスの定理です。
