図の外にある島：南鳥島（北緯24.3度・東経154.0度）、沖ノ鳥島（北緯20.4度・東経136.1度）。どちらも2枚の図の範囲より外にある。

この地図の国境は、2-1 で決めたとおり実効支配で描いています。北方領土（実効支配はロシア、日本が主張）と竹島（実効支配は韓国、日本が主張）は日本の範囲に含めていないので、そこでは層2の川や道路も描かれません。日本の地図帳とは描き方が異なります。尖閣諸島（日本が実効支配）は日本の側ですが、この縮尺では1〜2pxの点です。

この縮尺で入りきらないラベルは置いていない。データには全部ある（層3：都道府県名は47のうち39、都市名は20のうち18を表示）。層2の川・湖・道路・鉄道の名前も、動かないものから長い順に置き、重なるものは飛ばしている。ボタンの「なし」はデータに無いもので、これとは別。

2枚は同じ縮尺（経度を cos 36.63° = 0.8025 倍に縮めたうえで、1度 = 44px。どの国も同じ）。細い格子は1度、中くらいは5度、太い線は30度（2-1 の升目）。

層2の絞り込み（どの国にも同じ基準）：川は waterway=river のうち、同じ名前の区間をつないで長い順に15本。湖は natural=water かつ water=lake のうち広い順に10。高速道路は highway=motorway、主要幹線は highway=trunk（どちらも _link を除く全部）。高速鉄道は railway=rail かつ highspeed=yes、主要鉄道は railway=rail かつ usage=main（高速鉄道と重なるものは高速鉄道に入れる）。名前（ラベル）は name:ja、無ければ name。名前の無いものは線だけ引く。川は OSM の name ごとに数える。区間によって名前そのものが変われば別に数える（信濃川と千曲川）。同じ name の区間は、一部にだけ日本語名が入っていても1本として数え、ラベルには日本語名を使う（ライン川）。同じ名前の川がデータの上で途切れている（1km 以上離れている）ときは、つながずに別に数える（ドイツのエルベ川が2回出る）。つなげる判断を入れると国ごとに基準が揺れるため、データに書かれているとおりに数えている。湖の面積は、国の形を約2km広げた範囲で測っている。国境をまたぐ湖は、隣の国の側の湖面も含む（フランスのレマン湖は347km²と出るが、フランス側だけなら約234km²）。国境で切ると、同じ湖が国によって違う大きさになるため、切っていない。

ラベルの順：ラベルは動かないものから先に置く（湖→川→高速鉄道→高速道路→主要鉄道→主要幹線、同じ種類の中は長い順、重なるものは飛ばす）。川と湖は地形で何百年も動かないが、道路と鉄道は人が作ったもので増えたり廃止されたりする。骨組みとして先に立つのは地形のほう。長さだけで順を決めると、国道のラベルが川を押しのける。

ラベルの名前：道路の名前は、国によって書き方が違う。日本は「東名高速道路」のような固有の名前、チャドは「アベシェ - アティ - ンジャメナ」のような結ぶ町の列。どちらも直さずそのまま出している。1つの名前に複数の文字体系が並んでいるもの（「Lac Teli بحيرة تيلي」など）は、文字体系が変わったところで切って先頭の1つだけを出す（JR のような大文字の略号は切り替えに数えない）。アラビア文字だけ、キリル文字だけの名前はそのまま出す。1行は全角14文字（半角28文字）までとし、超えたものは末尾を「…」にする。切り詰めた結果、同じ図の中で見分けがつかなくなるものは、前ではなく後ろを残す（「…N'Djaména - Sarh/Bongor」のように先頭を「…」にする）。「起点 - 経由 - 終点」の形の名前は、前が共通で後ろで分かれるため。図の枠からはみ出すラベルは置かない。

層の使い方：層は1つずつ重ねて使う。全部を同時に出した状態は確かめのためのもので、覚えるための面ではない。

図：本教材が作成。正距円筒図法、標準緯線 北緯36.63度（国の本土＝面積がいちばん大きい陸のかたまりの、面積で重みをつけた球面上の重心。海外領土や離島を含めると中心が本土から離れるため）。本土は東経128.2〜146.6度・北緯29.9〜46.2度、南西諸島は東経122.4〜130.4度・北緯23.6〜30.4度。圧縮後1度あたり44px。
