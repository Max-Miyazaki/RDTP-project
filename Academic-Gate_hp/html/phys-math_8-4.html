8-4　ガウスの定理とストークスの定理小さな箱と輪を、積み上げる

8-3 では、div を小さな箱で、rot を小さな輪で定義しました。この記事では、その小さな箱や輪を積み上げて、大きな立体や大きな面にします。

積み上げると、隣り合う箱や輪の間で、ある量がきれいに打ち消し合います。その結果、内側の div や rot を全部足したものが、外側の境界だけで決まるという2つの定理が得られます。8-3 で大きな円の線積分が「rot × 面積」と一致したのは、偶然ではなかったのです。

最後に、この2つの定理が、1変数の積分の基本定理や 8-2 の grad の線積分と同じ形をしていることを見て、8章をまとめます。

読み方：解答は必ず閉じたまま、紙で挑戦してください。

§01

小さな箱を積み上げる — ガウスの定理

8-3 §02 で、小さな箱（体積 \(dV\)）から出ていく量は \(\mathrm{div}\,\vec F\,dV\) であることを見ました。では、小さな箱をたくさん並べて大きな立体を作ったら、全体から出ていく量はどうなるでしょうか。

共有する面では打ち消し合う

隣り合う2つの箱 A と B を考えます。2つが共有する面を通って A から B へ流れる量は、A にとっては「出ていく量」、B にとっては「入ってくる量」です。A と B の「出ていく量」を足すと、この共有面の分はプラスとマイナスで打ち消し合います。

たくさんの箱で立体を埋め尽くしても、同じことが起こります。内側の面はどれも2つの箱に共有されているので、すべて打ち消し合います。残るのは、どの箱とも共有されていない外側の面を通って出ていく量だけです。

一方、各箱から出ていく量は \(\mathrm{div}\,\vec F\,dV\) なので、全部足すと 7章の3重積分になります。つまり、同じ「全体から出ていく量」を、2通りの方法で数えられるのです。

2つの数え方の結果を等しいとおくと、次の定理が得られます。

ガウスの定理 \[ \iint_S\vec F\cdot\vec n\,dA=\iiint_V\mathrm{div}\,\vec F\,dV \]

\(V\) は立体、\(S\) はそれを囲む閉じた表面、\(\vec n\) は外向きの法線ベクトルです。

左辺は表面から外へ出ていく量、右辺は中の湧き出しの合計です。閉じた部屋の中で湧いた水は、壁を通って出ていくしかない、ということを式にしたものです。

図では長方形に並べた箱で説明しましたが、立体がどんな形でも、表面に沿って細かく箱を並べていけば同じ議論ができます。閉じた面での面積分を、積分記号に丸を付けた「∯」で書く本もあります。

まず自力で

\(\vec F=(x,0,0)\) と、1辺 1 の立方体 \(0\le x,y,z\le1\) について、ガウスの定理の両辺をそれぞれ計算し、一致することを確かめてください。

HINT 1

左辺：立方体の6つの面のうち、\(\vec F\cdot\vec n\) が 0 でないのは \(x\) 軸に垂直な2つの面だけです。右辺：div を求めて体積で積分します。

1右辺を計算する
なぜ：div が分かれば、あとは体積の積分です。

\(\mathrm{div}\,\vec F=\dfrac{\partial x}{\partial x}=1\) で一定なので、右辺は \(1\times\)（体積 1）\(=1\) です。

2左辺：面を分けて考える
なぜ：\(\vec F\) は \(x\) 成分しかないので、\(y\) 軸・\(z\) 軸に垂直な面では \(\vec F\cdot\vec n=0\) です（流れが面に沿っている）。

残るのは \(x=1\) の面（\(\vec n=\vec e_x\)）と \(x=0\) の面（\(\vec n={-}\vec e_x\)）です。

32つの面を計算する
なぜ：どちらの面でも \(\vec F\cdot\vec n\) は一定なので、面積 1 を掛けるだけです。

\(x=1\) の面では \(\vec F\cdot\vec e_x=1\)、\(x=0\) の面では \(\vec F=\vec 0\) なので 0。合計は \(1\) で、右辺と一致します。

左の面からは何も入らず、右の面から 1 だけ出ていきます。その差 1 が、中で湧いた量（div ＝ 1 がどこでも一様）の合計です。面積分の計算を、体積積分の計算に置き換えられるのがガウスの定理の使いどころです。

計算ドリル（§01・全1問）

問1回る流れ \(\vec F=({-}y,\ x,\ 0)\) について、どんな閉じた面を取っても、そこから外へ出ていく量は 0 であることを、ガウスの定理を使って説明せよ。

自分の答えを出してから

div を計算すると

\[ \frac{\partial({-}y)}{\partial x}+\frac{\partial x}{\partial y}+0=0 \]

どこでも 0 です。ガウスの定理の右辺は \(\iiint0\,dV=0\) なので、左辺の出ていく量も 0 です。

面の形を1つも決めずに、答えが出ました。div が 0 の場では、どんな閉じた面でも、入った分だけ出ていく。8-3 の「回る流れは湧き出さない」を、領域全体の言葉に言い換えたものです。

この記事の到達目標
  • ガウスの定理を、小さな箱の積み上げから説明できる
  • ガウスの定理の両辺を計算し、一致を確かめられる
  • ストークスの定理を、小さな輪の積み上げから説明できる
  • ストークスの定理を使って、1周の線積分を面積分で計算できる
  • 4つの定理に共通する「内側と境界」の形を説明できる
前提として使うもの
  • 8-3：面積分、div、rot
  • 8-1・8-2：線積分、grad とポテンシャル
  • 7章：重積分、球座標、球の体積と表面積
§02

ガウスの定理を使う

外向きに広がる流れ \(\vec F=(x,y,z)\) と、原点を中心とする半径 \(R\) の球で、ガウスの定理の両辺を別々に計算してみます。

左辺：表面から出ていく量

球面の上の点では、\(\vec F\) は原点から外向きで長さ \(R\) です。外向きの法線 \(\vec n\) と同じ向きなので、\(\vec F\cdot\vec n=R\) がどこでも一定です。7-2 のドリルで求めた球の表面積 \(4\pi R^2\) を掛けて

\[ \begin{aligned}\iint_S\vec F\cdot\vec n\,dA&=R\times4\pi R^2\\&=4\pi R^3\end{aligned} \]

右辺：中の湧き出しの合計

\(\mathrm{div}\,\vec F=1+1+1=3\) で一定です。7-2 で求めた球の体積 \(\frac43\pi R^3\) を掛けて

\[ \begin{aligned}\iiint_V\mathrm{div}\,\vec F\,dV&=3\times\frac43\pi R^3\\&=4\pi R^3\end{aligned} \]

両辺が一致しました。

物理でのガウスの定理：逆2乗の法則の理由

電場について、ガウスの定理は「閉じた面を通り抜ける電場の量は、中にある電荷の総量で決まる」という形で使われます（ガウスの法則）。8-3 の「電場の湧き出し口は電荷」を、領域全体に足し上げた形です。

1つの点電荷を、半径 \(R\) の球で囲むと考えます。球の大きさを変えても中の電荷は同じなので、通り抜ける電場の量は \(R\) によらず一定です。ところが球の表面積は \(4\pi R^2\) で、\(R\) の2乗に比例して広がります。一定の量が \(R^2\) に比例する面積に広がるので、表面での電場の強さは \(\dfrac{1}{R^2}\) に比例して弱まります。

電気の力や重力が「距離の2乗に反比例する」のは、この理由によると読めます。重力についても、「閉じた面を通り抜ける重力場の量は、中の質量で決まる」という同じ形の法則が成り立ちます。電場のガウスの法則は電磁気学、重力の場合は古典力学と宇宙論のセクションで扱います。

まず自力で

\(\vec F=(x,y,z)\) と、1辺 1 の立方体 \(0\le x,y,z\le1\) について、ガウスの定理の両辺を計算してください。

HINT 1

左辺では、6つの面を「座標が 1 の面」と「座標が 0 の面」に分けます。座標が 0 の面では、法線方向の成分が 0 です。

1右辺
なぜ：div が一定なら、体積を掛けるだけです。

\(\mathrm{div}\,\vec F=3\)、体積 1 なので、右辺は \(3\) です。

2左辺：座標が 1 の面
なぜ：たとえば \(x=1\) の面では \(\vec n=\vec e_x\) で、\(\vec F\cdot\vec n=x=1\) です。

\(x=1\)、\(y=1\)、\(z=1\) の3つの面は、どれも \(\vec F\cdot\vec n=1\)、面積 1 なので、合わせて \(3\) です。

3左辺：座標が 0 の面
なぜ：たとえば \(x=0\) の面では \(\vec n={-}\vec e_x\) で、\(\vec F\cdot\vec n={-}x=0\) です。

3つの面とも 0 です。左辺の合計は \(3\) で、右辺と一致します。

球でも立方体でも、同じ流れ \((x,y,z)\) に対して「表面から出ていく量 ＝ 3 × 体積」が成り立っています。表面の形がどうであれ、中の湧き出しの合計で決まることが、2つの例で確かめられました。

計算ドリル（§02・全1問）

問1\(\vec F=(x^2,\ 0,\ 0)\) と、1辺 1 の立方体 \(0\le x,y,z\le1\) について、ガウスの定理の右辺（div の体積積分）を計算せよ。また、左辺（表面から出ていく量）と一致することを確かめよ。

自分の答えを出してから

右辺：\(\mathrm{div}\,\vec F=2x\) です。\(y,\ z\) の範囲はどちらも長さ 1 なので

\[ \int_0^1 2x\,dx=1 \]

左辺：\(\vec F\cdot\vec n\) が 0 でないのは \(x=1\) の面（値 \(1^2=1\)、面積 1）だけで、\(x=0\) の面では \(0\)。合計 \(1\) で一致します。

今度は div が一定ではなく、場所によって湧き出しの強さが違います。それでも、7章の累次積分で湧き出しを足し上げれば、表面から出ていく量と一致します。div が一定でないときこそ、右辺の体積積分が威力を発揮します。

§03

小さな輪をつなぐ — ストークスの定理

rot でも同じことをします。8-3 §03 で、小さな輪（面積 \(dA\)）を1周する線積分は、rot の面に垂直な成分を使って \((\mathrm{rot}\,\vec F\cdot\vec n)\,dA\) と書けることを見ました。小さな輪をたくさん並べて、大きな面を作ります。

共有する辺では打ち消し合う

隣り合う2つの輪 A と B を、どちらも同じ回り方（反時計回り）でたどります。共有する辺を、A は上向きに、B は下向きにたどることになります。線積分は向きを逆にすると符号が変わるので（8-1 §04）、この辺の分は打ち消し合います。

たくさんの輪で面を埋め尽くすと、内側の辺はすべて打ち消し合い、外周の辺だけが残ります。残った辺をつなぐと、面の外周を1周する道になります。

ストークスの定理 \[ \oint_C\vec F\cdot d\vec r=\iint_S\mathrm{rot}\,\vec F\cdot\vec n\,dA \]

\(S\) は面、\(C\) はその外周です。左辺の \(\oint_C\) は、8-1 §04 で導入した閉じた道を1周する線積分の記号で、積分記号に付いた丸は「道が閉じている（始点と終点が同じ）」ことを表します。§01 で紹介した閉じた面の記号「∯」の丸も、同じ意味です。

\(C\) をたどる向きと \(\vec n\) の向きは、右ねじの関係（\(C\) の回る向きに右ねじを回したとき、ねじが進む向きが \(\vec n\)）に取ります。

左辺は外周を1周する線積分、右辺は中の回り具合の合計です。

面が \(xy\) 平面にある場合は \(\vec n=\vec e_z\) で、右辺は rot の \(z\) 成分の重積分になります。

\[ \oint_C\vec F\cdot d\vec r=\iint_S\Big(\frac{\partial F_y}{\partial x}-\frac{\partial F_x}{\partial y}\Big)dx\,dy \]

この平面版はグリーンの定理とも呼ばれます。

8-3 の円の結果は、偶然ではなかった

8-3 §03 で、回る流れ \(({-}y,x,0)\) の半径 \(R\) の円の1周の線積分が \(2\pi R^2\) となり、「rot の \(z\) 成分 2 × 円の面積 \(\pi R^2\)」と一致しました。これはストークスの定理そのものです。rot が一定なので、右辺は「rot × 面積」になります。

逆に、rot がどこでも 0 の場では、どんな輪を取っても右辺は 0、つまり1周の線積分は 0 です。これが、8-1・8-2 で見た「道によらない線積分」の本当の理由です。

まず自力で

\(\vec F=({-}y,\ x)\) と、正方形 \(0\le x,y\le1\) について、外周を反時計回りに1周する線積分を、4つの辺に分けて直接計算してください。さらに、ストークスの定理の右辺と比べてください。

HINT 1

各辺では、辺に沿った成分だけが効きます。下の辺（右向き）では \(F_x\)、右の辺（上向き）では \(F_y\)、上の辺（左向き）では \({-}F_x\)、左の辺（下向き）では \({-}F_y\) を、辺の長さ 1 で積分します。

1下の辺（\(y=0\)、右向き）
なぜ：辺に沿った成分は \(F_x={-}y\) で、\(y=0\) では 0 です。

寄与は \(0\)。

2右の辺（\(x=1\)、上向き）
なぜ：辺に沿った成分は \(F_y=x=1\) で一定です。

寄与は \(1\times1=1\)。

3上の辺（\(y=1\)、左向き）
なぜ：左向きなので、辺に沿った成分は \({-}F_x=y=1\) です。

寄与は \(1\times1=1\)。

4左の辺（\(x=0\)、下向き）と合計
なぜ：辺に沿った成分は \({-}F_y={-}x=0\) です。

寄与は \(0\)。合計は \(0+1+1+0=2\) です。

右辺は、rot の \(z\) 成分が \(1-({-}1)=2\) で一定なので、\(2\times\)（面積 1）\(=2\)。一致します。

4つの辺を1つずつ計算する手間が、「rot × 面積」の1行で済みました。逆に、面積分を線積分で計算するほうが楽な場面もあり、どちら向きにも使えます。

計算ドリル（§03・全1問）

問1ずれる流れ \(\vec F=(y,\ 0)\) と、正方形 \(0\le x,y\le1\) について、外周を反時計回りに1周する線積分を、ストークスの定理を使って求めよ。また、4つの辺で直接計算して確かめよ。

自分の答えを出してから

ストークスの定理：rot の \(z\) 成分は \(0-1={-}1\) で一定なので、\({-}1\times1={-}1\)。

直接計算：\(F_y=0\) なので左右の辺は 0。下の辺（\(y=0\)）は \(F_x=0\) で 0。上の辺（\(y=1\)、左向き）は \({-}F_x={-}1\) で、寄与は \({-}1\)。合計 \({-}1\) で一致します。

上の辺では流れに逆らって進み、下の辺では流れがありません。その差し引きが負の値として残りました。8-3 の水車が右回りに回ったのと同じ事情で、「上ほど速い」ことが1周の線積分に現れています。

§04

積分の形と微分の形

ガウスの定理とストークスの定理は、「各点での性質（div・rot）」と「領域全体での量（面積分・線積分）」を結ぶ橋です。物理の法則は、どちらの形でも書くことができ、2つの定理で互いに行き来できます。

電磁気学の基本法則を2通りに書く
微分の形（各点で）積分の形（領域全体で）
電場の湧き出しは、その場所の電荷で決まる閉じた面を通り抜ける電場の量は、中の電荷の総量で決まる（ガウスの法則）
磁場には湧き出しがない閉じた面を通り抜ける磁場の量は、いつも 0
電場の回り具合は、磁場の時間変化で決まる輪を1周する電場の線積分は、輪を通り抜ける磁場の量の変化で決まる（電磁誘導の法則）
磁場の回り具合は、電流（と電場の時間変化）で決まる輪を1周する磁場の線積分は、輪を通り抜ける電流（と電場の量の変化）で決まる（アンペールの法則）

上の2行はガウスの定理で、下の2行はストークスの定理で、左右を行き来できます。式の形と意味は、電磁気学のセクションで扱います。

4つの定理に共通する形

8章で出会った定理を、1変数の積分と並べてみます。

1変数の積分（2章）：内側は区間、境界は両端の2点。

\[ \int_a^bF'(x)\,dx=F(b)-F(a) \]

grad の線積分（8-2）：内側は曲線、境界は両端の2点。

\[ \int_C\nabla f\cdot d\vec r=f(\mathrm B)-f(\mathrm A) \]

ストークスの定理：内側は面、境界は外周の曲線。

\[ \iint_S(\nabla\times\vec F)\cdot\vec n\,dA=\oint_C\vec F\cdot d\vec r \]

ガウスの定理：内側は立体、境界は表面。

\[ \iiint_V\nabla\cdot\vec F\,dV=\iint_S\vec F\cdot\vec n\,dA \]
内側で微分したものを足すと、境界での値になる

4つとも、左辺は「内側で微分したもの（\(F'\)、\(\nabla f\)、\(\nabla\times\vec F\)、\(\nabla\cdot\vec F\)）を、内側全体で足したもの」、右辺は「境界だけで決まる量」です。そして成り立つ理由も共通で、内側を細かく区切ると、隣どうしの境目で打ち消し合い、いちばん外の境界だけが残るからです。

大学の数学では、この4つは「微分形式」という言葉を使って、1つの定理（一般化されたストークスの定理）の特別な場合としてまとめられます。この教材では扱いませんが、名前だけ覚えておいてください。

まず自力で

ストークスの定理と 8-3 §04 の恒等式 \(\mathrm{rot}\,\mathrm{grad}\,f=\vec 0\) を使って、grad の場を1周する線積分がいつも 0 になることを示してください。8-2 の結果（道によらない）と矛盾しないことも確かめてください。

HINT 1

ストークスの定理の \(\vec F\) に \(\nabla f\) を入れると、右辺に \(\nabla\times\nabla f\) が現れます。

1ストークスの定理に入れる
なぜ：1周の線積分を、面積分に置き換えます。
\[ \begin{aligned}&\oint_C\nabla f\cdot d\vec r\\&=\iint_S(\nabla\times\nabla f)\cdot\vec n\,dA\end{aligned} \]
2恒等式を使う
なぜ：\(\nabla\times\nabla f=\mathrm{rot}\,\mathrm{grad}\,f=\vec 0\) です。

右辺の中身が 0 なので、1周の線積分は 0 です。

38-2 と比べる
なぜ：同じことを別の道筋で確かめます。

8-2 では \(\int_C\nabla f\cdot d\vec r=f(\mathrm B)-f(\mathrm A)\) でした。1周すると始点と終点が同じなので、\(f(\mathrm A)-f(\mathrm A)=0\)。一致します。

同じ結論に、「端点の差（8-2）」と「中の回り具合が 0（ストークス）」という2つの道筋でたどり着きました。定理どうしが矛盾なくかみ合っていることが、8章の道具が1つの体系になっている証拠です。

計算ドリル（§04・全1問）

問1口頭試問形式：次の3つを、公式を見ずに自分の言葉で説明せよ。
①ガウスの定理が成り立つのはなぜか。
②ストークスの定理が成り立つのはなぜか。
③1変数の積分・grad の線積分・ストークスの定理・ガウスの定理に共通する形は何か。

自分の答えを出してから

① 立体を小さな箱で埋めると、各箱から出ていく量は div × 体積。隣り合う箱が共有する面では、一方の「出ていく」と他方の「入ってくる」が打ち消し合う。全部足すと内側の面は消え、外側の表面を通り抜ける量だけが残る。

② 面を小さな輪で埋め、すべて同じ向きにたどると、各輪の1周の線積分は rot の垂直成分 × 面積。隣り合う輪の共有する辺は逆向きにたどるので打ち消し合い、外周を1周する線積分だけが残る。

③ 内側で微分したものを内側全体で足すと、境界だけで決まる量になる。内側を細かく区切ると、隣どうしの境目で打ち消し合い、いちばん外の境界だけが残るから。

この3つが澱みなく言えれば、この記事、そして8章は通過です。特に③は、2章の積分から8章までを1本の糸でつなぐ見方です。

8章のふりかえり

8章では、ベクトルと場（8-1）から始めて、スカラー場の坂を表す grad（8-2）、ベクトル場の湧き出しと回り具合を測る div と rot（8-3）を作り、それらを積分と結ぶ2つの定理（8-4）にたどり着きました。電磁気学と、その先の場の理論を読むための道具が、これでひととおりそろいました。

次章（9-1 行列は線形変換）への接続

これまでに、形の違う場面で同じ種類の計算に何度か出会っています。7-2 のヤコビアンでは、偏微分を4つ正方形に並べて「面積が何倍になるか」を計算しました。8-1 §03 では、座標軸を回したときの成分の変わり方を、\(\cos\alpha\) と \(\sin\alpha\) を並べた式で書きました。

どちらも、ベクトルを別のベクトルに移す、1次式の変換です。9章では、この変換を数を並べた行列として正面から扱います。

9-1 で扱う問い（予習用）
  • 座標軸の回転（8-1 §03）を、1つの記号でまとめて書くには
  • 行列とは何で、ベクトルにどう作用するのか
  • 7-2 の行列式が「面積の倍率」だったのはなぜか
  • 2つの変換を続けて行うことは、行列の何にあたるのか

鍵となる一言：行列は「数の表」ではなく、ベクトルを動かす操作そのものです。そう見ると、7-2 と 8-1 で別々に出てきた計算が、同じ1つのものに見えてきます。
