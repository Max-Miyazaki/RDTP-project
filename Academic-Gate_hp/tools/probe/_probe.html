What to read off it

FPS min decides it — the lowest FPS since the last reset, so it catches thermal throttling a first-paint reading misses. Leave the tab focused and let each side run ≥60s. Measurement path tells you whether frame ms is a real GPU-timer number (EXT_disjoint_timer_query_webgl2) or a frame-time estimate (fallback) — the page's telemetry uses the GPU timer where the browser exposes it. It'll be the same path for both sides on one machine.

The two sides

WORKING TREE is whatever html/index.html currently ships (the live stage-7 motif — today the drift 流). BASELINE is the frozen orbits engine (_probe-orbits.js, the git-HEAD engine at 3e942e0, Round-24) — the thing the current motif replaced. Absolute FPS varies by machine; the delta between the two is the test.

Ship / don't-ship — the delta vs baseline is the test

SHIP — working tree's FPS-min matches baseline's (within ~5) and its frame-ms is within ~1.5 ms.
MARGINAL — working tree trails by 5–12 FPS-min, or +1.5–4 ms. Judge by feel.
HOLD — working tree >12 FPS-min below baseline, or >4 ms more, or can't hold ~55 FPS.
The baseline is what the current motif replaced, so "working tree ≈ baseline" is the pass.
